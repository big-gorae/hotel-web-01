# MVP 이상현상 이미지 샘플

상태: MVP 적용 승인 완료. 선택된 시안은 정식 `resource/images/anomalies/`와 프레젠테이션 매니페스트에 연결했다.

## 샘플

| 대상 | 파일 | 1차 검수 |
| --- | --- | --- |
| 가짜 어머니 | `fake_mother_v1.png` | 욕조 안 배치, 커튼 가림, 시선과 조명 양호 |
| 이불 속 아이 | `child_under_blanket_v2.png` | v1보다 작은 어린아이 크기, 신체 노출 없음 |
| 붉은 세탁기 | `red_washer_v2.png` | 원형 문 닫힘, 유리 안 검붉은 덩어리, 하단 누출과 웅덩이 포함 |
| TV 귀신 최초 상태 | `tv_ghost_active_v1.png` | 작은 화면에서 무표정 얼굴 식별 가능 |
| TV 귀신 적대 상태 | `tv_ghost_hostile_v1.png` | 같은 화면 위치에서 악독한 표정 대비가 큼 |
| 내장 욕조 | `entrails_bathtub_v1.png` | 욕조 안에만 검붉은 특수효과 소품이 존재 |
| 빈 자살 로프 | `empty_hanging_rope_v1.png` | 빈 올가미와 넘어진 의자, 사람 없음 |

비교용 전체 이미지는 `mvp_sample_contact_sheet.jpg`에 모았다.

## 기존 리소스 재사용

등록되지 않은 아이 본체는 새 이미지 생성 없이 다음 3D 모델을 사용한다.

`resource/3d_models/dripping_gaze/dripping_gaze.glb`

## 생성 지시 요약

- 원본 사진의 카메라, 방 구조, 가구와 조명을 유지한다.
- 가짜 어머니는 욕조 안에서 커튼에 일부 가려진 성인 여성 형상으로 만든다.
- 이불 속 아이는 신체가 전혀 보이지 않는 작은 어린아이 크기의 quilt mound로 만든다.
- TV 귀신은 화면 안에만 존재하며 최초 무표정과 적대적 미소를 분리한다.
- 욕조는 비인체 고무관, 실리콘 시트, 젖은 천과 검붉은 젤로 채운다.
- 빈 자살 로프에는 사람이나 그림자를 넣지 않고 넘어진 의자만 둔다.
- 붉은 세탁기는 실제 원형 문을 닫은 상태로 유지하고 내부 덩어리와 하단 누출을 표현한다.

## 제외된 초안

- `child_under_blanket_v1.png`: mound가 어린아이보다 크게 읽혀 보류.
- `red_washer_manual_v1.png`: 유리 내부 표현과 누출이 약해 보류.
