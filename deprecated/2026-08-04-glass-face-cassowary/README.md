# Deprecated glass-face cassowary call

Status: deprecated since 2026-08-04.

This archive preserves the former three-call cassowary sequence used by the
front-glass-face anomaly. The live game now uses
`res://resource/sounds/anomalies/front_glass_face_barn_owl_call.ogg` instead.

The archived audio is intentionally outside `resource/`, is ignored by Godot
through `deprecated/.gdignore`, and is excluded from exported builds. Do not
reference it from live runtime code.
