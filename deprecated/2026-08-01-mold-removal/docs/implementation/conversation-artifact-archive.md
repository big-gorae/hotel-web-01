# Conversation Artifact Archive

This repository preserves the image-production artifacts created while building
the anomaly MVP so the work remains recoverable without the original chat.

## Permanent runtime and reference assets

- `resource/images/anomalies/`: images currently used by the game.
- `resource/images/references/`: canonical entity and phenomenon references.
- `resource/images/prev/`: replaced production images and earlier references.
- `resource/reference/`: raw reference imports retained with their original names.

## Generation archives

- `tmp/imagegen/`: manual composites, masks, intermediate overlays, MVP samples,
  and contact sheets.
- `image_workbench/`: SceneLock jobs, prompts, masks, source images, candidates,
  review crops, and result metadata.
- `image_workbench/conversation_archive/2026-07-26_room_105_closet_woman/`:
  the complete Room 105 closet-woman composite attempt and its repair-source job.

The Room 105 composite in that conversation archive was rejected during visual
review because the reference portrait remained a visible rectangle over the
door. It is preserved as provenance and must not replace the runtime anomaly
image without a new review.

No provider API keys are stored in these archive directories.
