# 스토리·Infinity 야간 근무 구조

이 문서는 두 플레이 모드의 하루 진행 방식과 이상현상 발생 원칙을 기록한다.

## 확정 방향

게임은 **고정 순서의 7일 스토리 모드**와 **무작위 무한 근무인 Infinity 모드**로 분리한다. 스토리를 수정할 때 무작위 결과에 의존하지 않으며, 반복 플레이용 무작위성은 Infinity에만 둔다.

- 스토리 모드는 7일 뒤 종료하며 메인 사건과 production 사건을 모두 Day 표로 고정한다.
- Infinity는 Day 제한 없이 계속되며 매일 재사용 가능한 메인 사건 1개와 production 사건 1개를 각각 추첨한다.
- 스토리 단서는 스토리 모드에서만 재생한다. Infinity는 첫 근무부터 전체 룰북을 열어 무작위 사건의 대응법을 확인할 수 있게 한다.
- 두 모드 모두 이상현상은 항상 하나씩 순서대로 발생한다.
- 스토리와 Infinity는 각각 `user://hotel_save.json`, `user://hotel_infinity_save.json`에 저장해 서로 덮어쓰지 않는다.
- 룰북을 읽고 실제 상황에서 문장의 의미를 깨닫는 경험을 본편의 핵심으로 삼는다.
- Day 시작에는 언니, 플레이어와 호텔에 관한 저장 가능한 스토리 단서를 배치한다.

## 동시 발생 금지

**활성 상태인 이상현상은 항상 최대 1개다.**

- 한 이상현상이 경고, 대응 또는 종료 단계에 있다면 다른 이상현상은 시작하지 않는다.
- 다음 이상현상은 현재 이상현상이 해결되거나 실패 처리된 뒤에만 시작한다.
- 옷장 대기, 전화 대기, 세탁기 변화처럼 백그라운드 타이머를 가진 시스템도 다른 이상현상 활성 중에는 치명 단계로 진입하지 않는다.
- 발동 조건을 만족한 이상현상은 사라지지 않고 대기열에 들어간다.
- 장소가 정해진 이상현상은 플레이어가 그 화면을 보고 있으면 대기열에 머물며, 다른 화면으로 이탈한 뒤에만 실제 상태와 연출을 적용한다.
- 현재 이상현상 종료 후 짧은 안전 시간을 둔 다음 대기열의 첫 이벤트를 시작한다.
- 아이의 노래, 여자 웃음, 전화벨, 세탁 완료 음악처럼 소리가 단서인 연출은 서로 겹치지 않는다.

이 원칙은 조작 복잡도를 낮추고, 플레이어가 실패 원인을 분명히 이해하게 하기 위한 확정 결정이다.

## 스토리 모드의 기본 흐름

1. 새 Day의 한국어·영어 스토리 단서를 한 시퀀스씩 공개한다.
2. 새 Day의 룰북 페이지가 추가된다.
3. 평범한 호텔 관리 업무를 수행한다.
4. 아래 고정표에 지정된 메인 사건과 production 사건이 빈 구간에 발생한다.
5. 두 사건을 순차 해결한 뒤 일반 업무로 돌아가 근무를 종료한다.

같은 날 여러 이상현상을 체험할 수는 있지만, 두 이상현상의 경고와 대응 시간이 겹쳐서는 안 된다.

## 스토리 모드 고정 등장표

| Day | 스토리 메인 사건 | Production 사건 |
|---:|---|---|
| 1 | 없음 | 없음 |
| 2 | 105호 옷장의 돼지 가면 남자 | 복도의 빨간 객실등 |
| 3 | 없음 | 107호의 매달린 여자아이 |
| 4 | 108호 전등 수리 요청 전화 | 따라오는 그림자 |
| 5 | 붉은 세탁기 | 108호 욕조의 내장 |
| 6 | 106호의 등록되지 않은 아이 | 끔찍한 화장실이 비치는 거울 |
| 7 | 109호 통과 | 없음 |

메인 표는 `scripts/horror/night_anomaly_director.gd`의 `STORY_PRIMARY_EVENT_BY_DAY`에서, production 표는 `scripts/horror/anomaly_content_catalog.gd`의 `STORY_EVENT_BY_DAY`에서 수정한다. 빈 문자열 또는 표에 없는 Day는 사건 없음으로 처리한다. Day 7은 109호 결말의 집중도를 위해 production 사건을 배치하지 않는다.

## Infinity 무작위 투입 방식

- Day 상한이 없으며 Day 7 이후에도 다음 근무로 진행한다.
- 메인 풀은 돼지 가면 남자, 전화, 붉은 세탁기, 등록되지 않은 아이, 이불 속 아이로 구성한다.
- 스토리 결말 전용인 109호 통과는 Infinity 풀에서 제외한다.
- Production 풀은 `anomaly_content_catalog.gd`의 `production_event_ids()` 전체를 첫 근무부터 사용한다.
- 각 근무 시작 시 메인 1개와 production 1개를 미리 추첨하고 세이브에 계획 ID와 RNG 상태를 저장한다. 불러오기 때문에 그날 사건이 바뀌지 않는다.
- 이미 경험한 사건은 다음 근무에서 다시 추첨될 수 있다.

## Production 사건 원칙

확정된 기현상 15종은 그날의 메인 엔티티를 대체하지 않는 짧은 관리 사건으로 사용한다. 세부 장소와 처리법은 [기현상 인덱스](anomaly-bible/phenomena/README.md)를 따른다.

- 스토리 모드는 위 Day 표만 사용한다.
- Infinity는 최소 Day 조건과 관계없이 production 풀 전체를 사용한다.
- 고정 메인과 production 기현상 중 먼저 조건을 만족한 사건이 활성화되고, 다른 쪽은 해결될 때까지 진행을 멈춘다.
- 미해결 기현상이 있는 동안 메인 엔티티와 다른 기현상은 모두 대기열에서 기다린다.
- 현재 production 사건 수는 고정표에 지정된 스토리 Day와 Infinity 모든 근무에서 최대 1개다. `MAX_PRODUCTION_EVENTS_PER_DAY = 1`을 문서와 코드의 기준값으로 사용한다.
- [매달린 여자아이](anomaly-bible/entities/hanging-girl.md)는 스토리 Day 3에 고정되며 Infinity production 풀에도 들어간다.

## Day별 신규 경험

### Day 1: 평범한 근무

- 객실과 호텔 관리 업무를 익힌다.
- 직접적인 치명 이상현상은 배치하지 않는다.
- 설명하기 어려운 작은 위화감만 남긴다.

### Day 2: 옷장의 돼지 가면 남자

- 전역에서 반복되는 돼지 울음과 105호의 열린 옷장을 연결한다.
- 열린 옷장을 오래 눌러 남자를 안으로 밀어 넣는 해결법을 배운다.

### Day 3: 매달린 여자아이

- 열린 109호 초기 조우는 현재 off 상태다.
- 107호의 매달린 여자아이를 고정 배치하고, 인형과 대화 선택을 통해 해결한다.

### Day 4: 받지 못한 전화

- 전화는 반드시 받아야 하지만, 통화에서 지목한 방에는 들어가면 안 된다는 모순된 규칙을 배운다.
- 따라오는 그림자는 전화 이벤트가 완전히 끝난 뒤에만 진행한다.

### Day 5: 붉은 세탁기

- 세탁실에 들어오면 처음부터 붉은 세탁기를 발견하고, 원형 홀드로 정지한 뒤 완료 음악 동안 눈을 감고 숨는 순서를 배운다.
- 세탁기를 발견하기 전에는 방치 시간이 흐르지 않지만, 발견 뒤 30초간 정지하지 않으면 사망한다.
- 완료 음악이 재생되는 동안 다른 이상현상은 시작하지 않는다.

### Day 6: 등록되지 않은 아이

- 아이와 가짜 어머니의 사건을 중심으로 진행한다.
- 눈을 감고 노래를 완료해 아이를 진정시키는 동안 다른 이상현상은 발생하지 않는다.

### Day 7: 109호의 마지막 규칙

- 109호 문을 열어 두고, 나오는 존재를 막지 않으며, 발소리가 멎을 때까지 돌아보지 않는다.
- 무작위 난이도보다 개발자가 설계한 순서와 스토리 연출을 우선한다.
- 이전에 배운 규칙을 순차적으로 되짚을 수는 있지만 동시에 시험하지 않는다.
- 프런트에서 복도로 처음 진입하면 `waiting` 상태가 자동 시작된다. 대기·발소리 중 복도를 떠나거나 열린 문을 누르면 사망하고, 발소리가 끝나면 그날 메인 일정이 완료된다.

## 구현 원칙

이상현상 디렉터는 다음 상태를 명시적으로 관리한다.

- `active_anomaly_id`: 현재 활성 이상현상. 없으면 빈 값.
- `pending_anomaly_queue`: 발동 조건을 만족했지만 대기 중인 이상현상.
- `inter_anomaly_cooldown`: 이상현상 종료 후 보장되는 짧은 안전 시간.

새 이상현상을 시작하기 전에는 반드시 `active_anomaly_id`가 비어 있는지 확인한다. 활성 이상현상의 전용 음악과 전역 사운드를 모두 정리한 뒤에만 다음 이벤트를 시작한다.

## 난이도 조정 원칙

난이도는 동시 발생 개수로 올리지 않는다. 대신 다음 값을 조절한다.

- 경고에서 치명 단계까지의 시간
- 이상현상 재등장 빈도
- 룰북을 확인할 수 있는 안전 시간
- 눈 감기 시야 범위
- 옷장 단계별 대기 시간과 전역 돼지 울음 간격
- 전화벨 간격

플레이어가 한 번에 판단해야 하는 이상현상은 끝까지 하나로 유지한다.
