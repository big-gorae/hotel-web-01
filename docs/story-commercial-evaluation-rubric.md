# 흥행형 스토리 게임 평가표

이 평가표는 **“이 작품이 서사적으로 얼마나 훌륭한가”가 아니라 “잠재 고객이 발견하고, 구매하고, 계속 플레이하고, 다른 사람에게 퍼뜨릴 가능성이 얼마나 높은가”**를 측정한다.

《NEKOPARA》처럼 선택지가 거의 없는 작품, 《DDLC》처럼 구조적 반전이 핵심인 작품, 《Detroit》처럼 선택이 상품인 작품, 《Ace Attorney》처럼 반복 플레이 문법이 강한 작품이 모두 높은 점수를 받을 수 있도록 구성했다.

---

## 1. 점수 계산 방식

각 항목을 **0~5점**으로 평가한 뒤 가중치를 곱한다.

| 원점수 | 기준                    |
| --: | --------------------- |
|   0 | 존재하지 않거나 작품에 방해된다     |
|   1 | 제작자 설명을 들어도 매력이 불분명하다 |
|   2 | 기능은 있지만 경쟁작보다 약하다     |
|   3 | 일반적인 상업작 수준이다         |
|   4 | 작품의 분명한 장점으로 작동한다     |
|   5 | 작품을 대표하는 강력한 판매 요소다   |

최종 계산:

> **항목 점수 × 가중치 = 반영 점수**

총점은 100점이다.

# A. 구매 전환력 — 35점

## 1. 한 문장 구매 약속 — 15점

**가중치 ×3**

작품의 고유명사와 세계관 설명 없이도, 플레이어가 무엇을 경험하는지 한 문장으로 설명되는가?

### 평가 질문

* 플레이어가 누구인지 알 수 있는가?
* 플레이어가 무엇을 하는지 알 수 있는가?
* 매력적인 대상이나 상황이 있는가?
* 실패 위험이나 갈등이 있는가?
* 다른 작품과 구별되는 요소가 있는가?

### 점수 기준

| 점수 | 상태                             |
| -: | ------------------------------ |
|  0 | 한 문장으로 설명할 수 없다                |
|  1 | 장르와 세계관만 설명된다                  |
|  2 | 줄거리는 이해되지만 구매 이유가 없다           |
|  3 | 기본적인 흥미는 전달된다                  |
|  4 | 대상 고객이 즉시 관심을 느낄 수 있다          |
|  5 | 문장 하나만으로 작품을 기억하고 남에게 설명할 수 있다 |

### 높은 점수를 받는 예

* “불안정한 인터넷 방송인을 30일 동안 관리해 최고의 스트리머로 만든다.”
* “증언 속 모순을 찾아 증거를 제시하고 법정을 뒤집는다.”
* “귀여운 연애 게임이 플레이어의 컴퓨터와 현실을 침범하기 시작한다.”

### 낮은 점수를 받는 예

> “아르카디움 제국력 713년, 제7마력전쟁 이후 기억을 잃은 주인공이 운명의 진실을 마주한다.”

설정은 있지만 플레이어가 무엇을 기대해야 하는지 보이지 않는다.

## 2. 특정 고객의 욕망 적중도 — 10점

**가중치 ×2**

모든 사람에게 무난한 작품이 아니라, 특정 고객이 강하게 원할 경험을 제공하는가?

### 평가 질문

* 어떤 사람이 이 작품을 반드시 사고 싶어 하는가?
* 연애, 보호, 추리, 공포, 통제, 구원, 복수 중 어떤 욕망을 자극하는가?
* 단순한 장르 선호보다 구체적인 판타지가 있는가?
* 경쟁작 대신 이 작품을 선택할 이유가 있는가?

### 점수 기준

| 점수 | 상태                       |
| -: | ------------------------ |
|  0 | 대상 고객을 정의할 수 없다          |
|  1 | “스토리 게임을 좋아하는 사람” 정도다    |
|  2 | 장르 고객은 있지만 욕망이 추상적이다     |
|  3 | 특정 취향의 고객층이 보인다          |
|  4 | 대상 고객에게 강한 판타지를 제공한다     |
|  5 | 취향이 맞는 고객은 무시하기 어려운 수준이다 |

좋은 정의:

> “불안정하고 위험한 캐릭터를 돌보면서 관계를 통제하고 싶은 플레이어.”

약한 정의:

> “감동적인 이야기를 좋아하는 10~30대.”

|  3 | 주연 캐릭터가 구별된다            |
|  4 | 한눈에 작품을 알아볼 수 있다        |

# B. 첫 플레이 유지력 — 20점

## 4. 첫 30분 약속 증명 — 10점

### 평가 질문

* 대표 캐릭터의 매력이 드러나는가?
* 게임의 고유한 행동을 직접 해보는가?
* 핵심 갈등이나 이상 현상이 발생하는가?
* “나중에 재미있어진다”에 의존하지 않는가?

### 점수 기준

| 점수 | 상태                            |
| -: | ----------------------------- |
|  0 | 30분 동안 설명만 이어진다               |
|  1 | 핵심 사건이 한 시간 이후에 시작된다          |
|  2 | 사건은 있지만 작품의 고유성이 약하다          |
|  3 | 기본적인 갈등과 매력이 등장한다             |

핵심은 모든 비밀을 공개하는 것이 아니다.

> **정답은 숨기되, 흥미로운 문제가 존재한다는 사실은 즉시 보여줘야 한다.**

# C. 핵심 경험의 상품성 — 25점

## 6. 플레이어 역할과 핵심 행동 — 10점

**가중치 ×2**

플레이어가 반복해서 하는 핵심 경험이 명확한가?

선택지가 반드시 필요하지는 않다. 작품 유형에 따라 기준이 달라진다.

### 키네틱·감상형

* 누구와 시간을 보내는가?
* 장면마다 관계가 진전되는가?
* 캐릭터의 새로운 면을 지속적으로 발견하는가?
* 대화, 보이스, 연출 자체가 충분한 보상인가?

### 선택·분기형

* 무엇을 결정하는가?
* 선택에 실제 비용이 있는가?
* 결과가 이후 장면에서 기억되는가?
* 다른 선택을 확인하고 싶은가?

### 시스템 결합형

* 어떤 수치나 자원을 관리하는가?
* 반복 행동이 캐릭터를 변화시키는가?
* 플레이 방식 자체가 이야기의 주제를 표현하는가?
* 성공과 실패의 차이가 명확한가?

### 점수 기준

| 점수 | 상태                          |
| -: | --------------------------- |
|  0 | 플레이어는 텍스트를 넘기는 것 외에는 역할이 없다 |
|  1 | 선택이나 시스템이 형식적으로만 존재한다       |
|  2 | 기본 구조는 있지만 작품만의 행동이 없다      |
|  3 | 반복 가능한 핵심 경험이 존재한다          |
|  4 | 핵심 행동이 작품의 대표 재미가 된다        |
|  5 | 행동 하나만으로도 작품을 설명할 수 있다      |

예:

* 《Ace Attorney》: 모순을 찾아 증거를 제시한다.
* 《Detroit》: 인물의 생사를 바꾸는 결정을 한다.
* 《NEEDY STREAMER OVERLOAD》: 방송인의 일정과 정신 상태를 관리한다.
* 《NEKOPARA》: 캐릭터와의 관계와 장면을 높은 시청각 품질로 감상한다.

# 점수 해석

|     총점 | 판정                                       |
| -----: | ---------------------------------------- |
| 90~100 | 매우 강한 상업형 콘셉트. 제작 품질과 노출이 확보되면 크게 성장할 구조 |
|  80~89 | 충분히 판매 가능한 강한 콘셉트. 약한 항목 1~2개를 보완할 가치가 큼 |
|  70~79 | 특정 고객에게는 통할 수 있으나 입소문이나 강한 팬층에 의존        |
|  60~69 | 스토리 자체보다 포장·초반·캐릭터·핵심 행동의 재설계가 필요        |
|  45~59 | 흥미로운 아이디어는 있지만 구매 이유가 명확하지 않음            |
|   0~44 | 본격적인 제작 전에 핵심 판타지와 고객을 다시 정의하는 편이 안전     |

## 중요 기준

**80점 이상이어도 모든 항목이 평균적인 작품보다, 일부 항목에서 5점을 받는 작품이 더 유리하다.**

예를 들어 다음과 같은 점수는 강하다.

* 캐릭터 매력 5
* 고객 욕망 5
* 구매 약속 5
* 나머지 항목 3~4

반대로 모든 항목이 3점인 작품은 총점이 준수해 보여도 대표 상품이 없다.

> 흥행작에는 대개 “이 작품 하면 이것”이라고 말할 수 있는 5점짜리 항목이 최소 2~3개 존재한다.

# 보정용 위험 감점

기본 점수를 계산한 뒤 다음 문제가 심하면 별도로 감점한다. 같은 문제가 기본 항목에 이미 충분히 반영됐다면 중복 감점하지 않는다.

| 위험 요소                               |     감점 |
| ----------------------------------- | -----: |
| 핵심 재미가 첫 1시간 이후에 시작됨                |     -5 |
| 고유명사와 세계관 설명 없이는 피치가 불가능함           |     -5 |
| 선택지가 많지만 실제 결과가 거의 같음               | -5~-10 |
| 핵심 매력을 공개하면 스포일러가 되고, 숨기면 홍보할 것이 없음 |     -5 |
| 주연 캐릭터가 기존 인기 캐릭터와 지나치게 유사함         |     -5 |
| 개발 규모가 현재 인력과 예산을 크게 초과함            | -5~-15 |
| 홍보 이미지와 실제 플레이 경험이 다름               |    -10 |
| 대상 고객이 서로 충돌함                       |     -5 |

예:

* 잔혹한 심리 호러를 홍보하면서 실제 플레이의 80%가 평범한 학원 일상이라면 기대 불일치가 발생한다.
* 선택형 게임을 홍보하면서 대부분의 선택이 두 장면 후 동일하게 합쳐진다면 강한 감점 대상이다.

# 기존 흥행 사례를 넣어본 보정 결과

아래 점수는 판매량의 우열이 아니라, 이 평가표가 어떤 작품을 높게 평가하도록 설계됐는지 보여주는 **개략적 검증값**이다.

| 작품                           | 예상 흥행 구조 점수 | 강한 항목                             |
| ---------------------------- | ----------: | --------------------------------- |
| 《NEEDY STREAMER OVERLOAD》    |     약 96~98 | 캐릭터 식별성, 동시대적 욕망, 시스템 결합, 공유성     |
| 《Doki Doki Literature Club!》 |     약 94~97 | 한 문장 약속, 초반 대비, 메타 구조, 방송 반응      |
| 《Detroit: Become Human》      |     약 93~96 | 선택 판타지, 결과 가시성, 고품질 비주얼, 토론성      |
| 《Ace Attorney》               |     약 92~96 | 핵심 행동, 에피소드 구조, 캐릭터, 반복 가능한 문법    |
| 《NEKOPARA》                   |     약 88~93 | 고객 욕망, 캐릭터 상품성, 시청각 보상, 낮은 진입 장벽  |
| 《13 Sentinels: Aegis Rim》    |     약 78~83 | 높은 감정·서사 보상, 캐릭터, 완주 후 해석         |
| 《The House in Fata Morgana》  |     약 69~75 | 감정적 여운과 서사 완성도는 높지만 진입성과 확산성이 제한적 |

《NEKOPARA》가 높은 점수를 받는 이유는 선택이나 복잡한 시스템 때문이 아니다.

* 고객의 욕망이 명확하다.
* 캐릭터가 즉시 식별된다.
* 상점 페이지에서 상품이 이해된다.
* 게임이 약속한 감정을 꾸준히 제공한다.
* 캐릭터 소비와 시리즈 확장이 가능하다.

반대로 《13 Sentinels》나 《Fata Morgana》는 서사적 평가가 높더라도, 핵심 매력을 구매 전에 단순하게 전달하기 어렵고 초반 진입 비용이 높기 때문에 흥행 점수는 상대적으로 낮아진다.

# 실제 평가에 필요한 입력 양식

다음 형식으로 게임 콘셉트를 정리하면 위 평가표에 바로 적용할 수 있다.

```text
작품명:

1. 게임 유형:
키네틱 / 선택 분기 / 시스템 결합 / 혼합

2. 한 문장 피치:
플레이어는 누구이며, 누구를 상대로, 무엇을 하고,
실패하면 어떤 일이 생기는가?

3. 핵심 고객:
어떤 취향과 욕망을 가진 플레이어인가?

4. 주인공:
원하는 것 / 결핍 / 숨기는 것

5. 대표 캐릭터:
외형적 특징 / 성격 / 주인공과의 관계 / 위험 요소

6. 핵심 플레이:
플레이어가 가장 자주 하는 행동은 무엇인가?

7. 첫 30분:
첫 사건, 첫 선택, 첫 목표, 첫 보상은 무엇인가?

8. 주요 감정:
플레이어가 반복해서 느껴야 할 감정은 무엇인가?

9. 대표 장면:
트레일러나 방송에서 보여줄 수 있는 장면은 무엇인가?

10. 분기와 결말:
무엇에 따라 결과가 달라지는가?

11. 예상 규모:
플레이타임 / 캐릭터 수 / 루트 수 / CG 수 / 개발 인원

12. 판매 형태:
플랫폼 / 예상 가격 / 무료 체험판 여부
```

평가 시에는 **총점뿐 아니라 5점 항목이 무엇인지**가 가장 중요하다. 90점짜리지만 모든 것이 고르게 좋은 작품보다, 82점이어도 캐릭터·피치·핵심 행동에서 확실한 5점을 가진 작품이 실제 시장에서는 더 강할 수 있다.
