# 이상현상 후보 목록

아직 정사로 확정되지 않았지만 발전 가능성이 있는 이상현상을 보관한다. 후보는 본편 일정이나 세부 기믹이 확정되기 전까지 정식 이상현상 인덱스에 포함하지 않는다.

## 천장의 손님

- 상태: 후보
- 예상 분류: 엔티티
- 장소 후보: 객실, 복도, 직원용 창고
- 핵심 입력: 객실과 복도의 전등 조작

팔다리가 비정상적으로 꺾인 여자가 호텔 천장을 기어 다닌다. 여자는 현재 연결된 공간 중 가장 밝은 곳으로 이동한다.

플레이어는 객실과 복도의 불을 순서대로 켜 여자를 빈 직원용 창고까지 유도한다. 여자가 창고 천장에 들어간 순간 차단기를 내려 빛을 끊고 문을 잠근다. 여자가 머무는 공간의 불을 직접 끄거나 이동 경로를 잘못 만들면 플레이어가 있는 방의 천장으로 떨어진다.

룰북 문구 후보:

> 천장에서 마찰음이 들리면 가장 가까운 빈 객실의 전등을 켜시오.

확정 전에 결정할 항목:

- 천장 존재의 외형과 곰팡이 돼지 가면 남자와의 관계
- 한 번에 조작 가능한 전등 범위
- 창고까지 유도하는 최소 이동 횟수
- 실패 시 즉사 여부와 점프스케어 연출
