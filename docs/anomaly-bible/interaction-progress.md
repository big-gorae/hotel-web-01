# 이상현상 진행 바

## 확정 목적

이상현상 처리는 한 번의 클릭으로 즉시 끝내지 않는다. 플레이어가 대상과 위험한 화면을 일정 시간 마주하도록 하며, 진행 바로 남은 시간을 전달한다.

## 확정 표시 방식

### 원형 진행 바

- 물체를 직접 길게 누르는 상호작용에 사용한다.
- 아이템을 장착하고 화면 속 대상에 사용하는 경우에도 사용한다.
- 대상 전체를 넓은 핫스폿으로 잡고 커서 주변에 원형으로 표시한다.
- 작은 전원 버튼, 플러그, 스위치와 배수 마개를 별도 핫스폿으로 만들지 않는다.

### 가로형 진행 바

- 특정 상태를 일정 시간 유지하는 상호작용에 사용한다.
- 눈 감기, 노래 부르기와 이불 속 아이 앞에서 버티기가 해당한다.
- 화면 하단에 가로 한 줄 형태로 표시한다.
- 이불 속 아이와 등록되지 않은 아이의 노래에 우선 적용한다.

## 시간 원칙

- 크기가 작고 위험도가 낮은 변화는 짧게 누른다.
- 크기가 크거나 존재의 얼굴과 신체가 보이는 변화는 더 오래 누른다.
- 정확한 요구 시간, 중단 시 진행도 감소 속도와 접근성 보정은 튜닝값이다.
- 진행 완료 메시지를 띄우지 않는다. 정상 이미지 복귀와 소리의 종료로 성공을 알린다.
- 단, 개별 기획에서 명시적으로 확정한 사건 대사는 예외다. 끔찍한 화장실 거울 처리 직후의 오염 안내 대사는 표시한다.
