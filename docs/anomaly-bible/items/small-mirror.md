# 작은 거울과 지옥의 거울

## 상태

- 분류: 이상현상 처리 아이템·오염 아이템
- 기본 아이템명: `작은 거울`
- 오염 후 아이템명: `지옥의 거울`
- 기본 아이템 ID: `small_mirror`
- 오염 아이템 ID: `hell_mirror`
- 연결 기현상: [끔찍한 화장실이 보이는 거울](../phenomena/horrific-bathroom-mirror.md)
- 기획 상태: 변환, Hand 위험, 세탁기 폐기와 근무 종료 위험 확정

## 확정 변환

1. 플레이어가 `작은 거울`을 Hand에 장착한다.
2. 끔찍한 화장실 거울 전체에 사용한다.
3. 영혼의 절규 같은 소리가 나고 큰 거울의 끔찍한 형상이 사라진다.
4. 다음 대사를 한 번 표시한다.

> 작은 거울로 끔찍한 형상이 옮겨졌다. 들고 있으면 영혼의 절규가 들려온다

5. 인벤토리의 `작은 거울`을 같은 슬롯의 `지옥의 거울`로 교체한다.
6. 변환 직후 `지옥의 거울`을 Hand에 자동 장착한다.

## 확정 Hand 위험

- `지옥의 거울`이 Hand에 있는 동안 아주 작은 음량으로 영혼들의 절규를 반복 재생한다.
- 인벤토리 설명은 Hand 위험과 세탁기 폐기 단서를 한국어·영어로 제공한다.
- 플레이어가 인벤토리에서 직접 Hand 슬롯을 비우거나 다른 아이템으로 교체해야 한다.
- Hand에 너무 오래 유지하면 플레이어가 사망한다.
- 자동으로 내려놓거나 안전 슬롯으로 옮겨 주지 않는다.

## UI와 구현 상태

- `작은 거울`과 `지옥의 거울`은 서로 다른 아이콘과 이름을 사용해 변환을 즉시 알아볼 수 있게 한다.
- 변환은 새 아이템을 추가하는 방식이 아니라 기존 슬롯의 아이템 상태를 교체하는 방식으로 처리한다.
- 절규 반복음은 Hand 장착 상태에만 연결한다. 인벤토리에 보관 중일 때는 재생하지 않는다.
- Hand에 12초 연속 유지하면 사망하고 내려놓으면 위험 시간은 초기화된다.
- 세탁실의 두 번째 세탁기에 장착한 `지옥의 거울`을 사용하면 문이 닫히고 세탁기·파손음과 함께 아이템이 사라진다.
- 근무 종료 시 인벤토리에 `지옥의 거울`이 남아 있으면 사망한다. Hand 장착 여부와 무관하다.
- 폐기 성공이나 문 개폐에는 별도 행동 설명 팝업을 표시하지 않는다.

## 기각된 추가 사용처
