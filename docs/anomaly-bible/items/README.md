# 이상현상 아이템

이 디렉터리는 이상현상 처리에 사용되거나 처리 결과 위험한 상태로 변하는 아이템을 관리한다.

| 아이템 | 상태 | 핵심 용도 | 문서 |
| --- | --- | --- | --- |
| 작은 거울 | 확정 | 끔찍한 화장실 거울의 형상을 받아 냄 | [small-mirror.md](small-mirror.md) |
| 지옥의 거울 | 확정 | 작은 거울이 오염된 상태. Hand에 오래 들면 사망 | [small-mirror.md](small-mirror.md) |

아이템의 획득 장소가 별도로 확정되지 않은 경우만 미정으로 둔다. `지옥의 거울`은 Hand 12초 연속 유지 시 사망하고, 내려놓으면 시간이 초기화되며, 두 번째 세탁기에 넣어 파괴해야 한다. 근무 종료까지 남아 있어도 사망한다.
