# 그림자

## 상태

- 분류: 엔티티
- 장소: 객실 구역, 복도와 프런트
- 연결 시스템: 장면 이동, 문 열기, 발소리, 프런트 벨, 화면 점멸, 전역 방치시간
- 성향: 악의적
- 기획 상태: 탐지법, 해결법과 방치 사망 확정

## 확정 콘셉트

그림자는 플레이어의 뒤를 따라오는 보이지 않는 존재다. 점프스케어가 발생하기 전까지 모습이나 실루엣을 보여주지 않는다.

플레이어가 이동하면 자신의 발소리와 문 여는 소리가 정상적으로 한 번 난 뒤, 같은 소리가 일정한 간격을 두고 한 번 더 들린다. 두 번째 소리는 그림자가 플레이어의 행동을 따라 한 것이다.

## 확정 발동과 위험

1. 다른 이상현상이 활성화되지 않은 상태에서 그림자가 플레이어에게 붙는다.
2. 발동 순간에는 UI, 대사와 시각 효과를 표시하지 않는다.
3. 다음 이동부터 발소리 또는 문 여는 소리가 두 번씩 들린다.
4. 복제 소리의 간격은 계속 동일하며 점점 짧아지지 않는다.
5. 발동과 함께 전역 방치시간이 흐른다.
6. 제한시간 안에 해결하지 못하면 플레이어의 위치와 관계없이 얼굴 중심 점프스케어로 사망한다.

그림자가 벨에 반응하기 전까지 VHS 효과, 화면 왜곡과 경고 메시지를 추가하지 않는다. 이 단계에서는 시각적으로 정상인 화면에서 소리만 이상해야 한다.

## 룰북 문구

그림자가 처음 등장할 수 있는 Day의 룰북에 다음 규칙을 추가한다.

> 누군가 따라온다면 벨을 여러 번 빠르게 울리고 도망치십시오.

규칙은 그림자의 정체나 해결 단계를 직접 설명하지 않는다.

## 확정 해결 순서

1. 그림자가 붙은 상태에서 플레이어가 프런트 벨을 한 번 울리면, 그림자도 고정된 간격 뒤 같은 벨을 한 번 따라 울린다.
2. 플레이어가 벨을 여러 번 빠르게 울리면 그림자가 갑자기 비명을 지르며 괴로워한다.
3. 이때부터 플레이어의 심장 소리가 들리고 화면이 빠르게 깜빡인다. 이는 발동 직후의 무시각 원칙에 대한 유일한 예외이며, 벨로 그림자를 괴롭게 만든 뒤에만 시작한다.
4. 플레이어는 곧바로 방을 여러 번 빠르게 오가는 장면 이동을 반복한다.
5. 요구 횟수를 채우면 그림자가 다시 비명을 지르고 사라지며 이벤트가 해결된다.

벨 연타 횟수, 연타 판정 시간, 방을 오가는 요구 횟수와 허용 시간은 **튜닝값**이다. 해결 도중에도 그림자는 사라지기 전까지 플레이어의 이동음과 벨소리를 따라 한다.

## 기각한 해결 방향

- 정지하고 일정 시간 기다리기
- 복제 소리의 간격이 짧아지는 행동 횟수 추격
- 빈 객실에 그림자를 가두기
- 두 번째 발소리에 맞춘 타이밍 입력
- 지나온 장소를 역순으로 되돌아가기
- 카세트 녹음기로 두 번째 발소리를 녹음해 거꾸로 재생하기

## 사망 연출

- 제한시간 종료 직전 플레이어 바로 뒤에서 두 번째 발소리를 한 번 들려준다.
- 짧은 정적 뒤 사람과 닮았지만 사람이 아닌 얼굴이 화면을 덮는다.
- 그림자의 전체 몸과 평상시 외형은 끝까지 공개하지 않는다.

## 구현 식별자

- 이벤트 ID: `hotel_following_shadow`
- 상태: `idle`, `attached`, `bell_distressed`, `resolved`, `fatal`
- 전역 제한시간: `shadow_neglect_seconds`
- 복제 소리 간격: 고정 튜닝값
- 벨 연타 횟수와 판정 시간: 튜닝값
- 방 왕복 횟수와 판정 시간: 튜닝값
