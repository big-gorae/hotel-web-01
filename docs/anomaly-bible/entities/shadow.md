# 그림자

## 상태

- 분류: 엔티티
- 장소: 객실 구역과 복도
- 연결 시스템: 장면 이동, 문 열기, 발소리, 전역 방치시간
- 성향: 악의적
- 기획 상태: 탐지법과 방치 사망 확정, 해결법 미정

## 확정 콘셉트

그림자는 플레이어의 뒤를 따라오는 보이지 않는 존재다. 점프스케어가 발생하기 전까지 모습이나 실루엣을 보여주지 않는다.

플레이어가 이동하면 자신의 발소리와 문 여는 소리가 정상적으로 한 번 난 뒤, 같은 소리가 일정한 간격을 두고 한 번 더 들린다. 두 번째 소리는 그림자가 플레이어의 행동을 따라 한 것이다.

## 확정 발동과 위험

1. 다른 이상현상이 활성화되지 않은 상태에서 그림자가 플레이어에게 붙는다.
2. 발동 순간에는 UI, 대사와 시각 효과를 표시하지 않는다.
3. 다음 이동부터 발소리 또는 문 여는 소리가 두 번씩 들린다.
4. 복제 소리의 간격은 계속 동일하며 점점 짧아지지 않는다.
5. 발동과 함께 전역 방치시간이 흐른다.
6. 제한시간 안에 해결하지 못하면 플레이어의 위치와 관계없이 얼굴 중심 점프스케어로 사망한다.

VHS 효과, 화면 왜곡과 경고 메시지를 추가하지 않는다. 시각적으로 정상인 화면에서 소리만 이상해야 한다.

## 해결법 미정

다음 방향은 기각했다.

- 정지하고 일정 시간 기다리기
- 복제 소리의 간격이 짧아지는 행동 횟수 추격
- 빈 객실에 그림자를 가두기
- 두 번째 발소리에 맞춘 타이밍 입력
- 지나온 장소를 역순으로 되돌아가기
- 카세트 녹음기로 두 번째 발소리를 녹음해 거꾸로 재생하기

사진 기반 장면 이동과 기존 핫스폿 구조에서 별도 판정 충돌 없이 구현할 수 있는 새 해결법이 필요하다.

## 사망 연출

- 제한시간 종료 직전 플레이어 바로 뒤에서 두 번째 발소리를 한 번 들려준다.
- 짧은 정적 뒤 사람과 닮았지만 사람이 아닌 얼굴이 화면을 덮는다.
- 그림자의 전체 몸과 평상시 외형은 끝까지 공개하지 않는다.

## 구현 식별자

- 이벤트 ID: `hotel_following_shadow`
- 상태: `idle`, `attached`, `resolved`, `fatal`
- 전역 제한시간: `shadow_neglect_seconds`
- 복제 소리 간격: 고정 튜닝값
