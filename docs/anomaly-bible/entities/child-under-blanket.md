# 이불 속 아이

## 상태

- 분류: 엔티티
- 장소: 비어 있는 객실의 침대
- 연결 시스템: 객실 진입, 눈 감기, 가로형 진행 바, 전역 방치시간
- 성향: 악의적
- 기획 상태: 외형, 접촉 금지, 해결법과 사망 음성 확정

## 확정 콘셉트

비어 있어야 하는 객실의 이불이 웅크린 아이의 형태로 불룩 솟아 있다. 크기는 어린아이 정도지만 이불 밖으로 신체를 직접 보여주지 않는다.

플레이어가 방에 들어오면 이불 속에서 아이가 주기적으로 웃는다. 이불을 걷거나 눌러 정체를 확인하면 즉시 죽는다.

## 확정 위험

1. 아이를 발견하면 전역 방치시간이 흐르기 시작한다.
2. 방을 나가도 방치시간은 계속 흐른다.
3. 시간이 지날수록 웃음소리가 더 무섭고 비인간적으로 변조된다.
4. 제한시간이 끝나면 모든 언어 설정에서 공통으로 일본어 `"미츠케타—"` 음성이 들린다.
5. `"미츠케타—"`는 한국어로 `"찾았다—"`라는 뜻이다.
6. 짧은 유예 후 아이 또는 사람과 비슷한 얼굴이 화면을 덮으며 전역 점프스케어로 사망한다.

## 확정 해결

1. 이불을 건드리지 않는다.
2. 아이가 있는 방 안에서 눈을 감는다.
3. 눈을 감으면 화면 하단에 가로형 진행 바가 나타난다.
4. 눈을 감고 있는 동안 해결 진행 바가 차고 사망 카운트는 정지한다.
5. 기다리는 동안에도 아이의 웃음소리는 계속 들린다.
6. 진행 바가 완료되면 웃음이 멎고 이불이 평평해진다.
7. 이불이 평평해지면 해결된다.

눈을 감는 동안 추가 노래나 별도 버튼 입력은 요구하지 않는다.

## 즉사 조건

- 이불 또는 침대 핫스폿을 눌러 확인하려는 행동
- 이불에 아이템 사용
- 이불을 정리하거나 드래그하는 행동

이불에 커서를 올려도 경고 문구를 띄우지 않는다.

## 다른 아이와의 구분

- 등록되지 않은 아이: 눈을 감은 뒤 사용 버튼을 눌러 노래해야 한다.
- 이불 속 아이: 눈을 감은 상태 자체를 유지하면 된다.

## 룰북 문구 초안

> 빈 객실의 이불이 사람의 형태로 솟아 있을 경우 침대를 정리하지 마시오.

> 해당 객실에서 눈을 감고 웃음이 멎을 때까지 기다리시오.
