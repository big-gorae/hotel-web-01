# 받지 못한 전화

## 상태

- 분류: 엔티티
- 장소: 프런트 데스크와 전화가 지목한 객실
- 현재 연결 객실: 108호
- 연결 시스템: 프런트 전화, 벨 횟수, 객실 진입 제한
- 기획 상태: 핵심 기믹 확정, 전화의 정체와 사망 연출 미정

## 확정 기믹

1. 프런트 전화가 울리기 시작한다.
2. 전화를 너무 오래 받지 않으면 플레이어가 사망한다.
3. 전화를 받으면 상대는 특정 객실로 오라고 지시한다.
4. 통화를 들은 뒤에는 상대가 지목한 객실에 당분간 들어가면 안 된다.
5. 금지 시간이 남아 있을 때 해당 객실에 들어가면 사망한다.

전화는 받아야 하지만, 전화의 지시는 따르면 안 된다. 이 모순이 이상현상의 핵심이다.

전화를 제한 횟수 안에 받지 않으면 벨소리가 멎고 누군가 수화기를 드는 소리가 들린다. 이어서 수화기 너머 웃음소리가 들리고, 몇 초 뒤 플레이어의 현재 위치와 관계없이 얼굴 중심 점프스케어로 사망한다. 전화선이 공간을 따라 이어지는 연출은 사용하지 않는다.

## 현재 프로토타입

- Day 4부터 발생한다.
- 13번째 벨이 울릴 때까지 받지 않으면 사망한다.
- 통화 내용은 108호의 전등을 수리하러 오라는 요청이다.
- 통화 후 108호에 진입하면 사망한다.
- 현재는 진입 금지가 영구 플래그처럼 유지되므로, 최종 구현에서는 ‘당분간’에 맞는 해제 조건이나 시간을 추가해야 한다.

Day 4, 13번째 벨, 재발 간격과 객실 금지 시간은 모두 **튜닝값**이다. 현재 정사에서 지목 객실은 108호지만, 향후 변형 이벤트에서 다른 객실을 부르게 할지는 **미정**이다.

## 서사 원칙

- 통화 상대가 실제 투숙객인지, 관리자와 관련된 존재인지, 호텔 자체의 목소리인지는 미정이다.
- 목소리는 플레이어에게 도움을 청하기보다 객실 안으로 유인하려는 악의를 가진다.
- 플레이어가 전화를 받은 순간, 지목된 방은 평범한 공간에서 함정으로 바뀐다.

## 룰북 문구

> 108호에서 전등 수리 요청 전화가 걸려 올 경우, 요청을 무시하시오. 객실에 들어가지 마시오.

> 프런트 전화는 13번째 벨이 울리기 전에 받으시오.
