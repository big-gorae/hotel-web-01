# 옷장의 돼지 가면 남자

- 분류: 엔티티
- 주 활동 구역: 105호 옷장
- 최초 등장: Day 2
- 연결 시스템: 전역 대기, 응시가 강화되는 옷장 단계, 홀드 상호작용, 전역 돼지 울음

## 핵심 설정

창백한 돼지 가면을 쓴 성인 남자가 105호 옷장 안에서 아주 천천히 문을 밀고 나온다. 호텔 어디에 있든 낮고 젖은 돼지 울음이 들리면 이미 옷장 문이 열리기 시작한 것이다.

남자는 한 번에 뛰쳐나오지 않는다. 첫 단계부터 좁은 문틈의 한쪽 눈이 플레이어를 보고, 다음 단계에는 문이 더 열리며 두 눈과 가면 대부분이 드러난다. 플레이어가 끝까지 방치하면 남자는 플레이어의 현재 위치와 관계없이 바로 앞에 나타난다.

## 진행

1. 스토리 Day 2 또는 Infinity 메인 추첨에서 선택된 근무에, 다른 이상현상이 없는 동안 닫힌 상태로 90~180초의 랜덤 대기가 흐른다. 이 구간은 페이즈가 아니다.
2. 시각 1단계 `door_open`이 시작되고 한쪽 눈과 가면 일부가 보이는 좁은 문틈이 30초 동안 유지된다.
3. 시각 2단계 `emerging`이 시작되면 문이 더 열리고 두 눈과 가면 대부분이 40초 동안 정면을 응시한다.
4. 각 시각 단계 시작 시 울음이 한 번 들리고, 활성 상태에서는 30초 기준 ±10초 jitter 간격으로 반복된다.
5. 마지막 대기까지 방치하면 전역 사망 처리와 정식 점프스케어가 발생한다.

모든 단계 타이머는 플레이어가 105호 밖에 있어도 계속 진행된다. 다른 이상현상이 활성 상태일 때는 최초 대기만 멈추며, 이미 열린 옷장은 다른 콘텐츠의 발동을 막는다.

## 해결

1. 돼지 울음을 들으면 105호 옷장을 확인한다.
2. 열린 옷장 위에서 마우스를 누른 채 유지한다.
3. 5초 홀드를 끝까지 유지하면 남자를 안으로 밀어 넣고 문을 닫는다.
4. 중간에 손을 떼거나 커서가 옷장을 벗어나면 진행도는 초기화된다.

아이템과 눈 감기는 필요하지 않다. 해결 후 해당 Day의 이벤트는 종료되고 울음도 멎는다.

## 비주얼 규칙

- `door_open`은 좁은 문틈 속 돼지 가면의 한쪽 눈과 주둥이 일부를 보여 주며 첫 단계부터 정면 응시가 읽혀야 한다.
- `emerging`은 문틈이 더 넓어져 두 눈과 가면 대부분이 보이지만 남자는 옷장 밖으로 나오지 않는다.
- 목과 몸은 두 단계 모두 문짝과 어둠으로 완전히 가린다.
