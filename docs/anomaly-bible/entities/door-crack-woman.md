# 문틈의 여자

## 상태

- 분류: 엔티티
- 장소: 105호
- 연결 시스템: 곰팡이 성장, 곰팡이 제거제, 눈 감기
- 성향: 악의적
- 기획 상태: 핵심 서사와 기믹 확정, 세부 수치 및 연출 구현 예정

## 확정 서사

105호의 검은 곰팡이는 단순한 오염이 아니라 옷장 안에 있는 여자가 방 밖으로 번져 나오는 흔적이다. 곰팡이가 충분히 자라면 여자가 옷장 문틈을 넓혀 호텔 전체에 영향력을 행사한다.

여자는 옷장에서 완전히 걸어 나오지 않는다. 옷장 문 사이로 얼굴만 빼꼼 내민 채 웃는다. 플레이어가 어디에 숨든 마지막 단계가 되면 바로 앞에 나타나 살해한다.

곰팡이를 제거하는 행위는 여자를 퇴치하는 것이 아니다. 여자가 방 밖으로 나오는 통로를 일시적으로 줄여 다시 옷장 안으로 밀어 넣는 행위다.

## 발동과 전역 압박

1. 105호의 곰팡이가 6스택에 도달하면 이벤트가 시작된다.
2. 플레이어의 현재 위치와 관계없이 호텔 전역에서 기괴한 여자 웃음소리가 들린다.
3. 곰팡이 이후의 옷장 이상현상은 2단계로 진행되며 플레이어가 105호 밖에 있어도 계속 진행된다.
4. 두 번째 단계의 제한시간이 끝나면 플레이어가 어느 위치에 있더라도 점프스케어와 함께 사망한다.

전체 약 10초는 최초 목표 **튜닝값**이다. 실제 호텔 이동 시간과 난이도 테스트에 맞춰 조정할 수 있다.

## 위협 2단계

### 1단계: 옷장문 열림

- 105호의 옷장 문이 조금씩 열린다.
- 호텔 전역에서 낮고 먼 여자 웃음소리가 들린다.
- 문틈에는 아직 얼굴이 보이지 않는다.

### 2단계: 문틈의 얼굴과 전역 사망

- 여자가 옷장 문 사이로 얼굴을 빼꼼 내민다.
- 얼굴은 옷장 밖으로 완전히 나오지 않는다.
- 웃음소리가 더 가까워지고 방향을 특정하기 어려워진다.
- 이 단계부터 여자가 이미 나온 상태로 취급한다.
- 두 번째 단계의 제한시간이 끝나면 웃음소리가 플레이어 바로 곁에서 들린다.
- 호텔 내 어느 위치에 있더라도 얼굴 중심 점프스케어가 발생하고 사망한다.

## 해결 절차

1. 여자가 나온 상태에서 105호에 들어가면 눈이 강제로 감긴다.
2. 해결이 끝나기 전까지 임의로 눈을 뜰 수 없다.
3. 좁은 눈 감기 시야만 이용해 벽의 곰팡이를 찾는다.
4. 눈을 감은 상태로 곰팡이 제거제를 사용한다. 한 번 사용할 때 기존 규칙대로 2스택을 제거한다.
5. 곰팡이가 6스택 미만이 되면 여자가 문 안으로 물러나고 옷장 문이 닫힌다.
6. 웃음이 멎은 뒤 눈이 다시 열린다.
7. 같은 Day 동안 긴 재등장 유예 시간이 적용된다. 정확한 시간은 **튜닝값**이다.

여자나 옷장에 제거제를 직접 뿌려서는 해결되지 않는다. 반드시 벽의 곰팡이를 제거해야 한다.

## 연출 원칙

- 얼굴은 반드시 옷장 문 사이로만 빼꼼 보여준다.
- 웃음소리는 전역 타이머이자 가장 중요한 경고음이다.
- 퇴각할 때 얼굴을 다시 보여주지 않는다. 안쪽으로 끌려가는 소리와 문 닫히는 소리로 처리한다.
- 강제 눈 감기 이후에는 공포의 중심을 시각 정보에서 탐색과 소리로 전환한다.
