# `"죽어"`라고 적힌 안내판

## 상태

- 분류: 기현상
- 최소 등장: Day 3
- 장소: 프런트 체크아웃 안내판
- 이벤트 ID: `front_desk_death_sign`

## 확정 연출

정상 안내 문구가 있어야 할 표면에 붉고 거친 글씨로 `"죽어"`만 적혀 있다. 글씨가 새로 써지는 애니메이션은 없고, 플레이어가 프런트로 돌아왔을 때 이미 바뀌어 있다.

## 확정 처리

- Hand가 비어 있을 필요가 없으며 장착 중인 아이템의 종류를 검사하지 않는다.
- `"죽어"`로 변한 안내판 전체를 길게 누른다.
- 커서 주변의 원형 진행 바가 완료되면 정상 안내판으로 돌아간다.
- 안내판을 뒤집는 별도 애니메이션은 사용하지 않는다.

## 제작 메모

원본 안내판과 동일 구도의 사진 변형으로 제작해 추후 실제 휘갈긴 글씨 사진으로 쉽게 교체한다.
