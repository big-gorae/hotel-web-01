# 내장으로 가득한 욕조

## 상태

- 분류: 기현상
- 최소 등장: Day 3
- 장소: 108호 욕실 욕조
- 이벤트 ID: `room_108_entrails_bathtub`
- 기획 상태: 외형·4.2초 길게 누르기·배수음 확정

## 확정 연출

욕조가 끔찍한 내장과 검붉은 물로 가득 차 있다. 욕조 전체를 덮는 강한 공포 이미지다.

## 제작 제약

- 내장이 실시간으로 미끄러지거나 이동하는 애니메이션을 요구하지 않는다.
- 작은 배수 마개나 수도꼭지를 별도 핫스폿으로 만들지 않는다.
- 욕조 전체처럼 크게 보이는 영역만 상호작용 대상으로 사용한다.
- 필요하면 정지 이미지 상태 교체, 화면 가림과 음향을 사용한다.

## 확정 처리

욕조 전체를 4.2초 동안 길게 누른다. 완료하면 물과 내용물이 배수되는 소리가 재생되고 사건이 해결된다. 작은 배수 마개를 별도 핫스폿으로 만들거나 처리 안내창을 표시하지 않는다.

배수 마개 뽑기, 움직이는 내장 연출, 검은 봉투 수거, 노잣돈 또는 동전 투입은 사용하지 않는다.
