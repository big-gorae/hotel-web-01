# 끔찍한 화장실이 보이는 거울

## 상태

- 분류: 기현상
- 최소 등장: Day 2
- 장소: 106호 욕실 거울
- 이벤트 ID: `room_106_horrific_bathroom_mirror`
- 기획 상태: 외형과 해결법 확정

## 확정 연출

실제 욕실은 멀쩡하지만 거울 안에는 끔찍하게 훼손된 다른 화장실이 비친다. 거울 밖의 실제 공간은 정상이다.

## 확정 해결법

1. `작은 거울`을 Hand에 장착하고 끔찍한 화장실 거울 전체에 사용한다.
2. 영혼의 절규 같은 소리가 나고 큰 거울의 끔찍한 형상이 사라진다.
3. 다음 대사를 한 번 표시한다.

> 작은 거울로 끔찍한 형상이 옮겨졌다. 들고 있으면 영혼의 절규가 들려온다

4. 인벤토리의 `작은 거울`이 `지옥의 거울`로 바뀐다.
5. `지옥의 거울`은 자동으로 Hand에 장착된다.
6. Hand에 있는 동안 아주 작은 음량의 영혼 절규가 반복된다.
7. 플레이어가 직접 Hand에서 내려놓지 않고 너무 오래 들고 있으면 사망한다.

상세한 아이템 상태는 [작은 거울과 지옥의 거울](../items/small-mirror.md)을 따른다. 이 대사는 일반적인 처리 완료 메시지가 아니라 오염된 아이템의 새 위험을 알려 주는 확정 사건 대사다.

## 기각한 방향

다음 방향은 사용하지 않는다.

- 청소용 천으로 닦기
- 눈을 감고 처리하기
- 실제 샤워 커튼 상태를 거울 속 커튼과 반복해서 맞추기
- 소금을 뿌려 처리하기

## 충돌 규칙

등록되지 않은 아이가 활성 상태이거나 106호 화장실을 점유 중이면 발생하지 않는다.
