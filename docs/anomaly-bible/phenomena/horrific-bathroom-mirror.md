# 끔찍한 화장실이 보이는 거울

## 상태

- 분류: 기현상
- 최소 등장: Day 2
- 장소: 106호 욕실 거울
- 이벤트 ID: `room_106_horrific_bathroom_mirror`
- 기획 상태: 외형 확정, 해결법 미정

## 확정 연출

실제 욕실은 멀쩡하지만 거울 안에는 끔찍하게 훼손된 다른 화장실이 비친다. 거울 밖의 실제 공간은 정상이다.

## 해결법 미정

다음 방향은 기각했다.

- 청소용 천으로 닦기
- 눈을 감고 처리하기
- 실제 샤워 커튼 상태를 거울 속 커튼과 반복해서 맞추기
- 소금을 뿌려 처리하기

등록되지 않은 아이의 눈 감기와 겹치지 않고, 작은 수도꼭지나 스위치 이미지도 요구하지 않는 새 기믹이 필요하다.

## 충돌 규칙

등록되지 않은 아이가 활성 상태이거나 106호 화장실을 점유 중이면 발생하지 않는다.
