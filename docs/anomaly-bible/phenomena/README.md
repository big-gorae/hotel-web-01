# 기현상

기현상은 고유한 존재가 플레이어를 추적하지 않고 호텔 공간의 상태가 비정상적으로 변한 사건이다.

## 확정 원칙

- 객실 사진이나 설비 상태의 차이로 발견한다.
- 엔티티보다 짧고 간단한 현장 상호작용으로 처리한다.
- 한 번 클릭해 즉시 해결하지 않고 대상이나 상태에 맞는 진행 바를 사용한다.
- 물체를 누르는 행동은 원형 진행 바, 눈 감기처럼 상태를 유지하는 행동은 가로형 진행 바를 사용한다.
- 화면에 이미 크게 보이는 대상 전체를 핫스폿으로 잡는다. 작은 버튼, 플러그와 스위치를 새로 만들지 않는다.
- 처리 중 별도 설명, 정답 메시지와 아이템 오사용 경고를 띄우지 않는다.
- 정답 행동은 사진의 원상 복구와 사물음 변화로 전달한다.
- 발견하기 전에는 진행되거나 악화되지 않는다.
- 처리하면 해당 근무 동안 같은 기현상은 다시 나타나지 않는다.
- 엔티티가 활성화된 동안에는 새 기현상을 발생시키지 않는다.

세부 UI 규칙은 [이상현상 진행 바](../interaction-progress.md)를 따른다.

## 장소별 기억점

- **프런트**: 모니터, 유리문과 안내판을 사용한다. 얼굴은 프런트 벨과 연결한다.
- **세탁실**: 바닥, 천장, 왼쪽 벽, 정면 벽과 오른쪽 벽을 아기 얼굴 벽지의 다섯 처리 단위로 사용한다.
- **105호**: 액자와 손자국 거울을 사용한다. 곰팡이 돼지 가면 남자가 활성화된 동안에는 발생시키지 않는다.
- **106호**: 끔찍한 화장실 거울을 사용한다. 등록되지 않은 아이가 활성화된 동안에는 발생시키지 않는다.
- **107호**: 인간 가죽 수건과 빈 자살 로프를 사용한다. 목을 맨 목각 여자 인형과 동시에 발생시키지 않는다.
- **108호**: TV의 형상과 욕조의 내장을 사용한다. 받지 못한 전화가 이 방을 금지한 동안에는 발생시키지 않는다.
- **공용 욕실**: 닫힌 샤워 커튼은 어느 욕실에도 나타날 수 있지만 다른 욕실 기현상과 동시에 존재하지 않는다.

## 공통 충돌 규칙

- `active_anomaly_id`가 비어 있을 때만 시작한다.
- 같은 사진에서 두 기현상 레이어를 동시에 켜지 않는다.
- 동선을 제한하는 엔티티와 장소가 겹치면 추첨을 보류한다.
- 해결 직후 짧은 안전 시간을 적용한 뒤 다음 이상현상을 시작한다.
- 기현상에 보이는 얼굴, 손과 다리는 독립된 엔티티처럼 추적하거나 공격하지 않는다.
