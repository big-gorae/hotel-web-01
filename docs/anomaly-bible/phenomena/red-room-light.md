# 빨간색 객실등

## 상태

- 분류: 기현상
- 최소 등장: Day 2
- 장소: 객실 복도 105호 조명
- 이벤트 ID: `corridor_red_room_light`

## 확정 연출

105호 번호 옆 조명 하나만 선명한 적색으로 변한다. 주변 벽과 105호 문 아래까지 붉은 빛이 번지지만, 객실 안에는 별도 변화가 없다. 위치는 발생 때마다 바뀌는 값이 아니라 승인된 복도 사진과 핫스폿에 고정된 의도적 연출이다.

## 확정 처리

별도의 조명 스위치 이미지를 만들지 않는다. 붉어진 객실등 자체를 길게 눌러 원형 진행 바를 채운다. 누르는 동안 불이 깜빡이고, 완료되면 정상 전구색으로 돌아가 해결된다.

## 제작 메모

조명 본체 색뿐 아니라 벽면 광번짐까지 한 묶음의 오버레이로 교체한다.
