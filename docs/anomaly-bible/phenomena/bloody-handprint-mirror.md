# 빨간 손자국으로 꽉 찬 거울

## 상태

- 분류: 기현상
- 최소 등장: Day 3
- 장소: 105호 욕실 거울
- 이벤트 ID: `room_105_bloody_handprint_mirror`

## 확정 연출

크기가 서로 다른 붉은 손자국이 거울 표면을 빈틈없이 덮는다. 손자국 뒤로 플레이어의 형상이나 별도 귀신은 비치지 않는다. 핏방울은 아래로 흐르지만 바닥까지 번지지 않는다.

## 처리

청소용 천으로 거울을 한 번 길게 닦는다. 천이 지나간 영역부터 손자국이 지워지고 정상 거울로 돌아오면 해결된다.

## 충돌 규칙

105호의 곰팡이 또는 문틈의 여자 이벤트가 활성화된 동안에는 발생하지 않는다.
