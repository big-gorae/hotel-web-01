# 자살 로프가 걸린 방

## 상태

- 분류: 기현상
- 최소 등장: Day 3
- 장소: 107호 침실
- 이벤트 ID: `room_107_empty_hanging_rope`

## 확정 연출

107호 천장에 올가미가 매달려 있고 그 아래 의자가 옆으로 넘어져 있다. 로프에는 사람도 그림자도 없으며, 아주 약한 마찰음과 흔들림만 있다.

## 처리법 미정

작은 천장 고리를 누르거나 의자를 움직이는 방식은 사용하지 않는다. 로프와 매달린 공간 전체를 큰 핫스폿으로 사용할 수 있는 새 처리법이 필요하다.

## 엔티티와의 관계

이 기현상은 [매달린 여자아이](../entities/hanging-girl.md)의 시각적 복선이다. 빈 로프는 어디까지나 기현상이며 아이가 나타나거나 공격하지 않는다. 두 이벤트는 같은 시점에 절대 발생하지 않는다.
