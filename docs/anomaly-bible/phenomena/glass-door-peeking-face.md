# 유리문 너머 빼꼼 보이는 얼굴

## 상태

- 분류: 기현상
- 최소 등장: Day 3
- 장소: 프런트 출입 유리문
- 연결 대상: 프런트 벨
- 이벤트 ID: `front_desk_glass_peeking_face`
- 기획 상태: 외형과 벨 3연타 두 묶음의 처리법 확정

## 확정 연출

유리문 프레임 바깥쪽에서 얼굴 절반만 빼꼼 보인다. 얼굴은 호텔 안으로 들어오지 않고 플레이어가 다른 화면을 보고 돌아와도 같은 위치에 붙어 있다.

## 확정 처리

1. 유리문에 얼굴이 나타난다.
2. 프런트 벨을 빠르게 3회 누른다.
3. 세 번째 입력이 인정되면 얼굴의 표정이 더 악독하게 변한다.
4. 프런트 벨을 다시 빠르게 3회 누른다.
5. 두 번째 빠른 3연타가 인정되면 얼굴이 사라지고 해결된다.

얼굴을 닦지 않는다. 벨을 누를 때마다 얼굴이 다른 위치로 이동하는 연출도 사용하지 않는다.

## 입력 판정

- `빠른 3연타`의 허용 시간은 튜닝값이다.
- 첫 묶음과 두 번째 묶음 사이에는 시간제한을 두지 않는다.
- 느리게 누른 입력을 어떻게 초기화할지는 구현 튜닝으로 남긴다.
- 설명 메시지와 입력 횟수 UI는 띄우지 않는다.
- 벨 주변을 넓은 핫스폿으로 사용한다.

## 제작 리소스

- 평상시 유리문
- 최초 얼굴
- 악독하게 변한 표정
- 얼굴이 사라진 유리문
