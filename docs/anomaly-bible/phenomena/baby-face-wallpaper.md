# 아기 얼굴 벽지

## 상태

- 분류: 기현상
- 최소 등장: Day 3
- 장소: 세탁실
- 이벤트 ID: `laundry_baby_face_surfaces`
- 기획 상태: 장소, 다섯 처리 면, 음향과 해결 조건 확정

## 확정 연출

세탁실의 바닥, 천장, 왼쪽 벽, 정면 벽과 오른쪽 벽 전체가 괴로워하는 아기 얼굴로 바뀐다. 개별 얼굴을 각각 움직이거나 클릭하지 않는다.

각 면에 있는 모든 얼굴은 같은 상태를 공유한다.

## 확정 처리

1. 세탁실의 다섯 면을 각각 하나의 큰 핫스폿으로 사용한다.
2. 플레이어가 한 면을 누르면 그 면에 있는 모든 아기가 동시에 눈을 감는다.
3. 면을 누를 때마다 짧은 아기 울음소리를 한 번 재생한다.
4. 이미 눈을 감은 면을 다시 눌러도 별도 메시지는 표시하지 않는다.
5. 바닥, 천장, 왼쪽, 정면과 오른쪽의 눈을 모두 감기면 해결된다.

얼굴을 하나씩 감기는 연출은 제작하지 않는다. 다섯 면별로 `눈 뜸`과 `눈 감음` 두 상태만 준비한다.

## 구현 상태

- `open_surface_mask`: 아직 눈을 뜨고 있는 다섯 면의 비트 마스크
- `floor`
- `ceiling`
- `left`
- `front`
- `right`

모든 비트가 꺼지면 `resolved`로 전환한다. 한 면의 클릭을 길게 누르게 할지 한 번 누르게 할지는 전체 진행 바 구현과 함께 튜닝하되, 면 단위 처리 구조는 유지한다.

## 음향

- 면 처리마다 짧은 아기 울음 한 번
- 다섯 번째 면 처리 후 즉시 무음
- 등록되지 않은 아이의 지속 울음 및 노래 음향과 같은 재생 시간에 겹치지 않는다.
