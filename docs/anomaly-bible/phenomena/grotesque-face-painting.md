# 끔찍한 얼굴이 그려진 액자

## 상태

- 분류: 기현상
- 최소 등장: Day 3
- 장소: 105호 침실 액자
- 이벤트 ID: `room_105_grotesque_portrait`

## 확정 연출

평범한 그림이 피부가 흘러내리고 입이 비정상적으로 벌어진 얼굴 그림으로 바뀐다. 얼굴은 정지된 그림이며 눈동자가 움직이거나 액자 밖으로 나오지 않는다.

## 확정 처리

- Hand가 비어 있을 필요가 없으며 장착 중인 아이템의 종류를 검사하지 않는다.
- 끔찍한 얼굴로 변한 액자 전체를 길게 누른다.
- 커서 주변의 원형 진행 바가 완료되면 원래 그림으로 돌아간다.
- 액자를 벽 쪽으로 뒤집는 별도 애니메이션은 사용하지 않는다.

## 충돌 규칙

[옷장의 돼지 가면 남자](../entities/pig-mask-man.md)가 활성 상태이면 발생하지 않는다.
