# 끔찍한 얼굴이 그려진 액자

## 상태

- 분류: 기현상
- 최소 등장: Day 3
- 장소: 105호 침실 액자
- 이벤트 ID: `room_105_grotesque_portrait`

## 확정 연출

평범한 그림이 피부가 흘러내리고 입이 비정상적으로 벌어진 얼굴 그림으로 바뀐다. 얼굴은 정지된 그림이며 눈동자가 움직이거나 액자 밖으로 나오지 않는다.

## 처리법 미정

액자를 벽 쪽으로 뒤집는 방식은 이전 제안이며 아직 확정하지 않았다. 액자 전체를 넓은 핫스폿으로 사용할 수 있다.

## 충돌 규칙

105호 곰팡이 또는 [문틈의 여자](../entities/door-crack-woman.md)가 활성 상태이면 발생하지 않는다.
