# 수건 대신 걸린 인간 가죽

## 상태

- 분류: 기현상
- 최소 등장: Day 3
- 장소: 107호 욕실 수건걸이
- 이벤트 ID: `room_107_human_skin_towel`

## 확정 연출

접힌 수건 자리에 젖은 인간 가죽 한 장이 수건처럼 가지런히 걸려 있다. 피부 결, 점과 봉합 자국으로 즉시 알아볼 수 있지만 사람의 얼굴이나 완전한 신체 부위는 만들지 않는다.

## 처리법 미정

오염 폐기 봉투에 넣는 방식은 확정하지 않았다. 새로운 도구 구성이 정해진 뒤 처리법을 연결한다.

## 제작 메모

수건 영역의 변형 이미지와 떼어 내는 짧은 프레임만 사용한다. 가죽이 움직이거나 플레이어를 붙잡는 연출은 넣지 않는다.
