# 모니터에 귀신의 형상

## 상태

- 분류: 기현상
- 최소 등장: Day 3
- 장소: 프런트 데스크 모니터
- 이벤트 ID: `front_desk_monitor_ghost`

## 확정 연출

평소 업무 화면 대신 검은 화면 안에 귀신의 상반신 형상이 서 있다. 얼굴은 화면 가까이에 붙이지 않고, 꺼진 모니터가 방 안의 무언가를 반사하는 것처럼 흐리고 정지된 실루엣으로 보인다. 플레이어가 움직여도 형상은 화면 안에서 따라오지 않는다.

## 확정 처리

모니터 전체를 길게 누른다. 별도의 작은 전원 버튼을 만들지 않는다. 누르는 동안 화면이 깜빡이고 원형 진행 바가 차며, 완료되면 화면이 꺼지고 해결된다. 형상이나 다른 물건을 눌러도 메시지는 뜨지 않는다.

## 제작 메모

모니터 화면 영역만 교체하는 오버레이로 제작한다. 기존 VHS 노이즈를 약하게 섞되 눈 감기 상태에서는 노이즈를 표시하지 않는다.
