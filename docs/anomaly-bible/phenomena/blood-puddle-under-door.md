# 문 아래 피 웅덩이

## 상태

- 분류: 기현상
- 최소 등장: Day 2
- 장소: 객실 복도 105~108호 중 한 곳의 문 아래
- 이벤트 ID: `corridor_blood_puddle`

## 확정 연출

닫힌 객실 문 아래에서 검붉은 피가 흘러나와 얕은 웅덩이를 만든다. 피는 더 커지지 않으며 문을 열었을 때 객실 안에는 원인을 보여주지 않는다.

## 처리

청소용 천을 장착해 웅덩이를 한 번 닦는다. 닦는 동안 피가 문 아래로 되빨려 들어가듯 줄어들고 바닥이 정상으로 돌아온다.

## 충돌 규칙

전화가 진입을 금지한 객실과 엔티티가 점유한 객실 문에는 배치하지 않는다. 109호 문에는 절대 배치하지 않는다.
