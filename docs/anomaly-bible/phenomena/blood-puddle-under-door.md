# 문 아래 피 웅덩이

## 상태

- 분류: 기현상
- 최소 등장: Day 2
- 장소: 객실 복도 105호 문 아래
- 이벤트 ID: `corridor_blood_puddle`

## 확정 연출

닫힌 105호 문 아래에서 검붉은 피가 흘러나와 얕은 웅덩이를 만든다. 피는 더 커지지 않으며 문을 열었을 때 객실 안에는 원인을 보여주지 않는다. 위치는 승인된 복도 사진과 핫스폿에 고정하며 발생할 때마다 다른 방으로 옮기지 않는다.

## 처리

청소용 천을 장착해 웅덩이를 한 번 닦는다. 닦는 동안 피가 문 아래로 되빨려 들어가듯 줄어들고 바닥이 정상으로 돌아온다.

## 충돌 규칙

105호 동선을 점유하는 다른 사건과 동시에 활성화하지 않는다. 109호 문으로 옮겨 배치하지 않는다.
