# 지옥으로 향하는 비상 화살표

## 상태

- 분류: 기현상
- 최소 등장: Day 2
- 장소: 객실 복도에서 외부 비상계단으로 향하는 동선
- 이벤트 ID: `corridor_hell_exit_arrow`

## 확정 연출

정상 비상 유도등이 완전히 시뻘건 빛을 뿜으며 화살표가 외부 계단 아래쪽을 가리킨다. 붉은 빛 아래의 계단 끝은 검게 막혀 보이지만 실제 새 공간으로 이동하지는 않는다.

## 확정 처리

- Hand가 비어 있을 필요가 없으며 장착 중인 아이템의 종류를 검사하지 않는다.
- 시뻘겋게 변한 비상 유도등과 화살표 전체를 길게 누른다.
- 커서 주변의 원형 진행 바가 완료되면 정상 유도등과 계단 모습으로 돌아간다.
- 화면에 보이지 않는 작은 리셋 스위치는 만들지 않는다.

## 제작 메모

유도등, 주변 벽의 적색 광번짐, 계단 아래의 검은 마스크를 하나의 연출 세트로 관리한다.
