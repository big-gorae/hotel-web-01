# 확정 이상현상 단독 소재 생성 프롬프트 — 한국어

기준일: 2026-07-26

이 문서는 호텔 원본 사진을 입력하지 않고, 이후 로컬에서 합성할 **단독 소재**를 생성하기 위한 프롬프트다. 각 코드 블록은 공백 포함 800자 이하다. `STATE`가 있는 항목은 한 번에 한 상태만 생성하고, 승인된 최초 결과를 다음 상태의 참조 이미지로 사용한다.

## 공통 사용 규칙

- 인물·물체·얼룩: 투명 배경 PNG. 투명이 불가능하면 균일한 중간 회색 배경, 바닥과 투영 그림자 없음.
- 화면·그림·벽지: 정면 직사각형 텍스처. 프레임, TV, 모니터, 벽은 생성하지 않음.
- 빛: 검은 배경의 발광 패스. 합성 시 Screen/Add 사용.
- 호텔 방, 가구, 문틀 같은 합성 배경은 절대 생성하지 않음.

# A. 기현상

## P01. 모니터 귀신

```text
꺼진 LCD 화면에 넣을 정면 16:9 화면 텍스처. 거의 검은 편광 유리 속에 성인 인간의 머리와 양어깨가 아주 희미하게 반사되어 있다. 존재는 약간 아래, 중심에서 벗어나 있고 얼굴은 모공과 젖은 피부의 일부만 읽힌다. 눈·코·닫힌 입은 자세히 보면 인간임을 알 수 있으나 첫눈에는 반사 얼룩처럼 보여야 한다. 미세한 회색 정적과 유리 반사만 사용한다. 발광 눈, 해골, 거대한 입, 전형적인 흰 소복, 긴 머리로 가린 얼굴 금지. 모니터 베젤, 책상, 방, 사람의 전신, 글자, UI 없이 화면 내부 영상만 생성한다. 사실적인 야간 사진 질감, 낮은 대비, 16:9.
```

## P02. 유리문 너머 얼굴

```text
STATE=PEEK 또는 HOSTILE. 밤의 유리문 세로 틈에 나중에 배치할 성인 얼굴 반쪽의 사실적 컷아웃. 이마 일부, 한쪽 눈, 코 절반, 입 절반만 정면으로 보이고 나머지는 정확한 수직선 뒤에 가려진 형태다. PEEK는 깜빡이지 않는 눈과 너무 오래 유지한 작은 친절한 미소. HOSTILE은 같은 얼굴·각도·크기를 유지하고 눈만 비정상적으로 크게 뜨며 보이는 입꼬리를 악독하게 끌어올린다. 피부 모공과 약한 습기, 유리를 통과한 듯한 낮은 채도. 손, 몸, 피, 상처, 발광 눈 금지. 문틀·유리·건물·배경은 그리지 말고 투명 배경에 보이는 얼굴 부분만 생성한다.
```

## P03. “죽어” 안내판

```text
낡은 크림색 플라스틱 안내판 표면에 정확한 한글 두 글자 “죽어”가 굵고 거친 검붉은 안료로 급하게 쓰인 정면 텍스처. 디지털 폰트가 아니라 손가락이나 마른 붓을 여러 번 눌러 쓴 흔적이며 압력에 따라 획이 끊기고 갈라진다. 아주 짧은 아래 번짐과 마른 안료의 입자만 허용한다. 손, 손자국, 피가 흐르는 연출, 영어, 룬, 다른 문장 금지. 원근 없는 정면 사각형, 균일한 조명, 글자가 잘리지 않게 한다. 모델이 정확한 한글을 만들지 못하면 글자 없는 낡은 표면과 별도의 검붉은 붓질 알파 레이어를 생성한다.
```

## P04. 빨간 객실등

```text
낡은 저가 호텔의 작은 벽부형 객실등 하나가 깊고 포화된 적색으로 켜진 단독 사진 소재. 전구 중심은 밝은 적색이지만 유리 커버의 먼지, 긁힘과 금속 받침의 형태가 남아 있다. 정면에 가까운 3/4 각도, 사실적인 노출과 따뜻한 적색광. 장면 전체의 붉은 색보정, 경광등, 불꽃, 연기, 피 금지. 벽, 문, 객실 번호와 주변 방은 그리지 않는다. 투명 배경에 등기구만 만들고, 별도 결과로 동일한 위치의 부드러운 적색 광번짐을 검은 배경 발광 패스로 생성할 수 있게 명확한 실루엣을 유지한다.
```

## P05. 문 아래 피 웅덩이

```text
닫힌 문 아래에서 스며 나온 것처럼 한쪽 가장자리가 가늘고 길게 시작되는 검붉은 액체 웅덩이의 단독 알파 소재. 중앙은 점성 있고 거의 검은 적갈색, 얇은 가장자리는 젖은 붉은 반사와 불규칙한 혀 모양을 가진다. 얕고 정지된 액체이며 바닥 시점에 맞게 낮은 각도로 보인다. 발자국, 손자국, 시체, 장기, 머리카락, 끌린 흔적 금지. 문, 벽, 바닥 타일과 방은 생성하지 않는다. 투명 배경, 투영 그림자 없음, 반사광은 중립적으로 제한하여 이후 호텔 바닥에 색을 맞출 수 있게 한다.
```

## P06. 아기 얼굴 벽지

```text
STATE=EYES_OPEN 또는 EYES_CLOSED. 정면의 반복 가능한 정사각형 벽지 텍스처. 낡고 누렇게 변한 종이에 수십 개의 기이한 가상 아기 얼굴이 촘촘히 반복된다. 부은 눈꺼풀, 팽팽한 이마, 눌린 코, 울음 직전 반쯤 열린 입과 서로 다른 비대칭. 귀엽거나 장난감 같지 않고 오래된 인쇄가 잘못 복제된 초현실적 공포. EYES_CLOSED는 승인된 EYES_OPEN과 얼굴 수·배열·크기·입·얼룩을 동일하게 두고 눈꺼풀만 모두 힘주어 감는다. 실제 아동 사진, 상처, 피, 몸, 글자 금지. 완전 평면, 균일광, 이음새 없는 타일 텍스처.
```

## P07. 인간 가죽 수건

```text
수건처럼 반으로 접혀 걸릴 한 장의 젖은 가상 인간 피부 단독 컷아웃. 두껍고 무거운 회백색·얼룩진 분홍색 막이 중앙의 접힘을 따라 늘어지고, 아래 가장자리는 불규칙하다. 모공, 잔털, 작은 점, 피부색 변화와 몇 군데의 거친 봉합 흔적이 보여 천이 아님을 알 수 있다. 얼굴, 유두, 귀, 손가락, 팔다리, 문신, 몸통 실루엣과 흐르는 피 금지. 수건걸이, 벽, 욕실은 만들지 않는다. 정면에 가까운 3/4 각도, 투명 배경, 투영 그림자 없음, 젖은 부분에만 약한 중성 하이라이트.
```

## P08. 지옥행 비상 화살표

```text
아래 방향을 가리키는 낡은 비상 유도등 단독 소재. 단순하고 즉시 읽히는 아래쪽 화살표가 완전히 시뻘건 빛으로 과노출되며, 오래된 반투명 플라스틱 커버와 긁힌 금속 케이스가 남아 있다. 실제 지옥, 불꽃, 용암, 악마, 손, 사람, 글자와 새 통로 금지. 현대적 네온 장식이나 판타지 룬처럼 보이지 않게 한다. 정면에 가까운 각도, 투명 배경에 표지판만 생성한다. 별도 발광 패스는 검은 배경 위에 표지판 중심과 아래 방향으로 약하게 퍼지는 적색광만 포함한다.
```

## P09. 끔찍한 얼굴 액자 그림

```text
액자 안에 넣을 낡은 세로형 유화 텍스처. 정면을 보는 성인 얼굴은 인간으로 읽히지만 한쪽 눈이 지나치게 깊고 다른 눈은 조금 높으며, 볼살이 여러 겹 아래로 흐른다. 입은 턱의 한계를 넘게 넓게 벌어져 어둠 속 불규칙한 젖은 치아가 많고, 피해자의 비명이 아니라 관객을 알아본 악의적인 기쁨을 보인다. 갈라진 바니시, 누런 캔버스, 실제 붓자국으로 하나의 오래된 그림처럼 통일한다. 액자, 벽, 방, 손, 벌레, 흐르는 피, 발광 눈 금지. 정면 평면 이미지, 세로 4:5.
```

## P10. TV 귀신

```text
STATE=ACTIVE 또는 HOSTILE. CRT TV 화면에 넣을 정면 4:3 흑백 영상 텍스처. 창백한 성인 얼굴과 어깨 윗부분이 거친 정적과 주사선 안에서 카메라를 본다. ACTIVE는 눈과 닫힌 입이 작은 화면에서도 읽히는 거의 무표정. HOSTILE은 같은 얼굴·크기·위치를 유지하고 정적 대비를 높이며 눈을 크게 뜨고 입꼬리를 비정상적으로 올려 치아 일부가 보이는 악독한 웃음으로 바꾼다. 얼굴은 확대되거나 화면 밖으로 나오지 않는다. TV 베젤, 가구, 방, 전선, UI 금지. 화면 내부 영상만, 4:3, 상태 간 픽셀 정렬.
```

## P11. 샤워 커튼 안의 다리

```text
욕조 안에 누운 정체불명의 성인 하반신을 위한 두 다리 단독 컷아웃. 무릎 아래와 맨발이 가장 잘 보이고 허벅지는 화면 뒤쪽에서 자연스럽게 잘려, 누워 있는 자세가 즉시 읽힌다. 실제 중력과 욕조 길이에 맞는 편안하지 않은 정지 자세, 창백하고 젖은 피부, 약한 중성 하이라이트. 서 있는 다리, 카메라로 뻗은 발, 얼굴, 손, 몸통, 상처, 피, 부패와 신원 단서 금지. 욕조, 커튼, 타일, 욕실을 그리지 않는다. 투명 배경, 투영 그림자 없음, 가림 작업이 쉽도록 두 다리의 윤곽을 선명하게 유지한다.
```

## P12. 빈 목줄

```text
사람 없이 비어 있는 낡고 굵은 밧줄 올가미 단독 컷아웃. 위쪽 밧줄은 캔버스 밖 천장 방향으로 팽팽하게 이어지고, 아래에는 실제로 조여질 수 있는 매듭과 무게감 있는 타원형 고리가 수직으로 매달린다. 거친 섬유, 닳은 부분과 미세한 꼬임이 사실적이어야 한다. 사람, 아이, 머리카락, 옷 조각, 피, 그림자 형상, 의자, 가위 금지. 천장, 방, 침대와 고정 장치는 만들지 않는다. 정면에 가까운 3/4 각도, 투명 배경, 바닥 그림자 없음, 전체 밧줄이 잘리지 않게 세로형으로 생성한다.
```

## P13. 붉은 손자국 거울

```text
거울에 붙일 투명 데칼 시트. 서로 다른 크기와 압력의 검붉은 손자국이 거의 빈틈없이 겹친다. 손바닥, 손가락 끝, 옆으로 미끄러진 흔적, 오래 말라 갈색이 된 층과 더 젖은 붉은 새 층이 자연스럽게 섞인다. 일부에만 짧은 중력 방향 방울이 있다. 실제 손이나 팔, 얼굴, 플레이어 반사, 글자 금지. 동일 손자국의 기계적 반복 금지. 거울, 프레임, 세면대와 욕실은 생성하지 않고 손자국과 번짐만 투명 배경에 만든다. 가장자리 여백을 남긴 정면 직사각형 알파 소재.
```

## P14. 끔찍한 화장실 거울 속 공간

```text
거울 반사면에 넣을 정면 세로형 이미지. 낡은 타일 화장실이 불가능할 만큼 깊고 끝없는 복도로 이어지고, 비뚤어진 세면대와 변기가 멀어질수록 반복된다. 줄눈은 검게 젖고 배수구 주변에는 오래된 머리카락 덩어리와 검붉은 습기가 있다. 가장 먼 불투명 유리나 비닐 뒤에 사람 비슷한 흐린 형상 몇 개만 눌려 보인다. 중앙의 또렷한 얼굴, 아이, 손, 포털 테두리, 룬, 발광 마법 금지. 실제 거울과 욕실 외부는 그리지 않는다. 프레임 없는 정면 이미지, 깊은 원근, 세로 3:4.
```

## P15. 내장 욕조 내용물

```text
욕조에 채워 넣을 사실적인 가상 내장 더미의 단독 컷아웃. 굵기가 다른 회분홍색 장관, 짙은 적갈색 조직, 얇은 막과 응고된 혈액이 검붉은 물에 서로 눌리고 얽혀 넓고 낮은 타원형 덩어리를 이룬다. 값싼 붉은 국수나 광택 플라스틱이 아니라 최고급 공포영화 실물 보철의 물성. 머리, 얼굴, 눈, 손발, 완전한 팔다리, 태아, 몸통 금지. 살아 움직이거나 밖으로 기어 나오는 자세 금지. 욕조, 커튼, 욕실과 바닥은 만들지 않는다. 투명 배경, 투영 그림자 없음, 젖은 표면의 작은 중성 하이라이트만 유지한다.
```

# B. 엔티티

## E01. 옷장의 돼지 가면 남자

```text
ASSET=PIG_MASK_MAN_PEEK 또는 PIG_MASK_MAN_FATAL. PIG_MASK_MAN_PEEK는 승인된 레퍼런스와 동일한 창백한 살구빛 분홍색 돼지 가면의 좁은 문틈용 파편이다. 비교적 매끈한 표면, 높고 둥근 이마, 비대칭 귀, 낮게 놓인 작고 깊은 원형 눈구멍, 짧고 넓은 주둥이, 둥근 검은 콧구멍과 작은 입을 고정한다. 귀 일부, 한쪽 이마, 눈구멍 하나 전체와 옅은 회색 인간 눈, 주둥이 절반과 콧구멍 하나 전체·다른 콧구멍의 안쪽 가장자리만 남기고 두 번째 눈, 가면 전체와 몸은 전혀 보이지 않는다. 진흙이나 두꺼운 오염으로 가면 원형을 가리지 않는다. PIG_MASK_MAN_FATAL은 동일 가면의 정면 클로즈업이다. 숲, 검은 외투, 옷장, 문, 방, 여성 얼굴, 실제 돼지 머리, 다른 돼지 가면 디자인, 피범벅 상처 금지. 투명 배경.
```

## E02. 받지 못한 전화

```text
전역 사망용 정면 얼굴 컷아웃. 성별과 시대를 특정하기 어려운 성인 인간형이 플레이어 바로 옆에서 수화기 너머의 웃음을 계속하는 순간. 한쪽 뺨이 렌즈에 조금 더 가까워 미세하게 비대칭이고, 눈은 전혀 웃지 않은 채 정면을 보며 입만 지나치게 넓은 조용한 웃음으로 벌어진다. 귀 옆에 오래된 검은 전화 수화기의 곡선 일부만 흐릿하게 허용한다. 전화선, 숫자, 방 번호, 호텔 제복, 특정 상처, 피, 발광 눈 금지. 얼굴이 가로 프레임의 70% 이상을 차지하며 배경은 완전한 어둠, UI 없음, 사실적인 젖은 피부의 작은 반사만 사용한다.
```

## E03. 붉은 세탁기

```text
ASSET=DRUM_CONTENTS 또는 FATAL. DRUM_CONTENTS는 닫힌 세탁기 원형 유리 뒤에 넣을 정면 원형 영상 소재다. 검붉은 물속에서 굵기가 다른 관 모양 조직과 접힌 살점 같은 무거운 유기물이 천천히 뒤집혀 눌리고, 곡면 유리와 물 때문에 일부만 흐리다. 단순 붉은 조명 금지. FATAL은 같은 유리 바로 뒤에 눌린 젖은 인간형 얼굴의 정면 클로즈업으로, 눈·코·입은 읽히지만 물과 회전 자국이 피부를 옆으로 밀고 입은 즐겁게 웃는다. 세탁기 본체, 세탁실, 완전한 팔다리와 외부 장기 금지. 원형 밖은 투명.
```

## E04. 등록되지 않은 아이와 가짜 어머니

```text
`resource/images/references/entities/room_106_fake_mother/reference_face_01.png`와 동일한 가짜 어머니의 전신 단독 컷아웃. 살구빛 피부, 젖은 긴 검은 머리, 크게 뜬 창백한 눈, 짙은 검은 눈두덩, 검게 칠한 코, 넓게 고정된 검은 미소와 목 오른쪽의 붉은 자국을 바꾸지 않는다. 젖고 낡은 무채색 환자복을 입고 몸은 정면이며 목만 미세하게 잘못된 각도로 기울어진다. 반투명 유령, 안전한 손짓, 아이를 안은 자세, 시체, 출산, 탯줄, 피 묻은 배와 추가 상처 금지. 욕실과 아이는 만들지 않는다. 투명 배경, 전신이 잘리지 않게 한다.
```

아이 본체와 점프스케어는 이미지 생성 없이 `resource/3d_models/dripping_gaze/dripping_gaze.glb`를 사용한다.

## E05. 109호 열린 문

```text
109호 존재의 전역 사망용 정면 얼굴. 나이와 성별을 단정할 수 없는 사람 비슷한 얼굴이 완전한 암흑에서 렌즈 바로 앞에 드러난다. 얼굴 외곽과 귀는 검정에 삼켜져 경계가 사라지지만, 두 눈의 작은 젖은 반사, 납작하게 눌린 코, 양 끝이 지나치게 멀리 이어진 닫힌 입은 즉시 읽힌다. 실종된 언니, 호텔 직원, 특정 인물로 보일 의상이나 단서 금지. 방 번호, 문, 복도, 몸통, 손, 연기, 발광 눈, 피 금지. 얼굴이 가로 화면의 70~80%를 차지하고 배경은 식별 불가능한 검정, UI 없음.
```

열린 문과 내부 암흑은 생성형 이미지가 아니라 기존 문 스프라이트와 로컬 마스크로 제작한다.

## E06. 그림자

```text
보이지 않던 그림자 엔티티의 전역 사망용 얼굴. 단순 검은 실루엣이 아니라 눈·코·입이 분명한 성인 인간형이다. 잿빛 피부는 빛을 거의 반사하지 않고 얼굴 바깥쪽은 완전한 어둠과 합쳐진다. 두 눈에는 아주 작은 젖은 반사, 코는 사람보다 조금 납작하고, 닫힌 입은 양 끝이 너무 멀리 이어져 미소처럼 보인다. 마지막 복제 발소리를 플레이어 바로 뒤에서 낸 듯 얼굴이 가로 프레임의 75%를 차지하는 친밀한 거리. 피, 과장된 이빨, 발광 눈, 연기 몸통, 추가 그림자와 방 배경 금지. UI 없는 가로형 단일 이미지.
```

`attached`에서는 이미지가 전혀 없으며 복제된 발소리, 문 소리와 프런트 벨만 사용한다. 벨 연타 뒤의 `bell_distressed`에서도 엔티티 이미지는 추가하지 않고 런타임 화면 점멸만 사용한다.

## E07. 이불 속 아이

```text
ASSET=MOUND 또는 FATAL. MOUND는 낡은 꽃무늬 이불 아래 어린아이가 무릎을 가슴에 붙이고 옆으로 웅크린 사람형 융기. 작은 머리, 굽은 등과 두 무릎 덩어리가 한 장의 천 아래 자연스럽게 이어지고, 천의 두께·주름·재봉선과 눌린 매트리스 모양이 사실적이다. 얼굴·손발·틈은 보이지 않는다. FATAL은 같은 꽃무늬 천의 검은 틈에서 나온 둥근 아이형 얼굴의 정면 클로즈업. 눈은 성인처럼 의식적이고 입은 숨바꼭질에서 찾아낸 기쁨으로 넓게 웃는다. 실제 다친 아이, 피, 상처, 침대와 방 금지. 투명 배경.
```

## E08. 목을 맨 목각 여자 인형

```text
낡은 드레스를 입은 여자아이 형태의 목각 인형. 얼굴·목·팔·다리는 사람 피부가 아니라 나뭇결, 벗겨진 칠, 관절 이음새와 얕은 균열이 분명한 오래된 나무다. 팽팽한 올가미에 수직으로 매달려 발은 바닥에서 떨어지고 팔은 축 늘어지며, 얼굴은 정면을 보고 해맑지만 불쾌하게 웃는다. 피, 목 상처, 실제 피해 아동처럼 보이는 피부, 화면을 감싸는 팔 금지.
```
