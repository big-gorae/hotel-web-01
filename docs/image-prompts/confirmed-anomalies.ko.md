# 확정 이상현상 이미지 생성 프롬프트 — 한국어 검토본

기준일: 2026-07-26

이 문서는 현재 바이블에서 확정된 **기현상 15종**, **엔티티 8종**, 그리고 제작에 직접 연결되는 거울 아이템의 최종 이미지 제작 프롬프트다. 지금은 이미지를 생성하지 않는다. 한국어판을 먼저 검토하고 수정한 뒤, 같은 ID의 영어판에 똑같이 반영한다.

## 읽는 법

- `정사 확정`: 이미 확정된 외형이나 연출이다.
- `미술 제안`: 엔티티의 정확한 얼굴처럼 아직 정사로 정하지 않은 부분을 이미지로 만들 수 있을 만큼 구체화한 제안이다. 검토 후 확정해야 한다.
- 각 자산은 아래의 `공통 편집 마스터 프롬프트`와 해당 자산의 `개별 프롬프트`를 이어 붙여 사용한다.
- 여러 상태가 있는 자산은 매번 처음부터 새로 만들지 않는다. 먼저 승인된 첫 상태를 다음 생성에도 참조 이미지로 넣어 얼굴, 물체 위치, 렌즈와 픽셀 정렬을 고정한다.
- `점프스케어`는 배경 합성 이미지와 별개의 전면 자산이다. 점프스케어가 필요한 항목에는 `점프스케어 마스터 프롬프트`도 함께 붙인다.

## 공통 편집 마스터 프롬프트

```text
당신은 사실적인 실물 특수효과와 절제된 심리 공포를 전문으로 하는 최고 수준의 호러 영화 미술감독이자 이미지 합성가다. 제공된 SOURCE_IMAGE는 이 게임의 확정된 배경 사진이며 절대적인 기준이다. 이것은 새로운 장면을 그리는 작업이 아니라, 원본 사진 안의 지정된 영역에 단 하나의 이상현상만 정밀하게 합성하는 작업이다.

카메라 위치, 렌즈 화각, 원근, 크롭, 해상도, 벽·바닥·천장의 구조, 문과 창문의 위치, 모든 가구와 설비, 기존 소품, 노출, 화이트밸런스, 그림자 방향을 원본과 픽셀 단위로 보존하라. 개별 프롬프트가 명시적으로 허용한 영역만 바꾸고 그 밖의 픽셀은 가능한 한 원본과 동일하게 유지하라. 방을 넓히거나 재설계하지 말고, 물체를 옮기거나 새 출입구를 만들지 말며, 요청하지 않은 사람·얼굴·손·그림자·글자·피·안개를 추가하지 마라.

결과는 실제 낡은 저가 호텔에서 밤에 촬영한 사진처럼 보여야 한다. 새로 추가한 요소는 기존 광원과 정확히 같은 색온도, 광량, 접촉 그림자, 반사, 가림, 초점 심도와 센서 노이즈를 가져야 한다. 공포는 번쩍이는 판타지 효과가 아니라, 실제 공간에 있을 법한 물성과 잘못된 인간성에서 나와야 한다. 값싼 핼러윈 소품, 고딕 장식, 마법진, 룬 문자, 과도한 안개, 푸른 달빛, 영화 포스터식 색보정, 과장된 비네트, 생성형 이미지 특유의 녹고 뒤틀린 배경을 사용하지 마라.

게임 UI, 커서, 진행 바, 자막, 워터마크, 테두리와 레터박스를 넣지 마라. 런타임 VHS 효과가 별도로 적용되므로 장면 전체에 강한 VHS 줄무늬나 글리치를 굽지 마라. 단, 모니터나 TV 화면 내부의 정적 잡음은 해당 프롬프트가 요구할 때만 허용한다. 출력 캔버스와 픽셀 크기는 SOURCE_IMAGE와 정확히 같아야 하며, 상태 교체 시 카메라와 배경이 흔들리지 않도록 완전히 정렬된 full-scene 결과를 출력하라.
```

## 점프스케어 마스터 프롬프트

```text
이 이미지는 전역 사망 시 화면을 덮는 단 한 프레임의 얼굴 중심 점프스케어 자산이다. 배경은 식별할 수 없을 만큼 어둡고 얕아야 하며, 동일 엔티티의 승인된 조우 이미지가 있다면 얼굴 정체, 머리카락, 피부와 의상 단서를 정확히 이어받아야 한다. 얼굴은 정면 또는 거의 정면에서 프레임의 65~85%를 차지하고, 눈·코·입이 즉시 읽혀야 한다. 사람과 닮았지만 미세하게 잘못된 비율과 악의적인 표정으로 공포를 만들고, 추상적인 검은 얼룩이나 단순 해골로 대체하지 마라.

팔이 화면을 감싸거나 손이 렌즈를 잡는 연출, 피가 렌즈에 튀는 연출, 큰 글자, 속도선, 만화식 왜곡, 과도한 모션 블러를 사용하지 마라. 얼굴의 핵심 윤곽은 작은 화면과 짧은 노출에서도 읽히도록 하되 전체를 균일하게 밝히지 말고, 눈과 젖은 피부의 작은 반사만 실제 광원처럼 남겨라. 출력은 1536×1024, UI 없는 가로형 단일 이미지로 만든다.
```

```text
STATE B 이후를 만들 때는 SOURCE_IMAGE와 승인된 직전 상태 이미지를 모두 참조하라. 카메라, 배경, 대상의 정체, 머리카락 가닥, 얼굴 골격, 의상, 물체의 실루엣과 위치를 고정하고, 상태 설명에 명시된 변화만 수행하라. 상태 사이에 인물의 나이·성별·얼굴·옷·자세가 임의로 바뀌거나 대상이 카메라 쪽으로 이동해서는 안 된다. 모든 상태는 알파 블렌딩 없이 서로 교체해도 배경 픽셀이 튀지 않는 완전 정렬 이미지여야 한다.
```

```text
프런트 사진 오른쪽의 큰 업무용 LCD 모니터 화면만 편집하라. 밝은 업무 화면을 전원이 꺼진 듯한 거의 검은 유리 화면으로 바꾸고, 그 검은 화면 안에 흐린 성인 인간의 상반신 형상을 보여라. 형상은 모니터 속 영상처럼 발광하지 않고, 플레이어 뒤의 어두운 공간에 실제로 서 있는 무언가가 꺼진 패널에 희미하게 반사된 것처럼 보여야 한다. 머리와 양어깨는 읽히되 얼굴은 편광 유리와 약한 정적 때문에 한 번에 완전히 해석되지 않게 하라. 얼굴을 화면 가까이에 붙이지 말고, 화면 중앙보다 약간 아래와 한쪽으로 벗어나게 두어 우연히 발견한 반사처럼 만든다.

모니터 베젤, 받침대, 키보드, 책상과 방 전체는 원본 그대로 유지한다. 모니터 밖에 인물이나 대응 그림자를 추가하지 않는다. 빛나는 눈, 벌어진 괴물 입, 긴 검은 머리로 얼굴을 전부 가린 전형적인 귀신, 해골과 검은 사각형을 사용하지 않는다. 정지된 형상이어야 하며 플레이어를 따라오는 시선이나 화면 밖으로 나오는 연출을 암시하지 않는다. 작은 화면에서도 상반신의 존재는 읽히지만, 첫눈에는 단순 반사로 오인할 수 있는 농도로 완성하라.
```

## P02. 유리문 너머 빼꼼 보이는 얼굴

- 이벤트 ID: `front_glass_face`
- 소스: `resource/images/front_desk.png`
- 산출물: `peek`, `hostile`
- 상태: 위치와 2단계 표정 변화는 정사 확정. 얼굴 정체는 미술 제안.

```text
프런트 중앙 유리 출입문의 바깥쪽, 지정된 세로 문틀 뒤에서 성인 인간의 얼굴 절반만 호텔 안을 빼꼼 들여다보게 하라. 마스크가 없다면 관객 기준 유리문의 왼쪽 세로 문틀을 사용한다. 이마 일부, 한쪽 눈, 코 절반과 입 절반만 보여야 하며 나머지는 문틀 바깥에 가려져야 한다. 얼굴은 유리 표면에 붙은 인쇄물이나 내부 부유물이 아니라 실제로 밤의 바깥 통로에 서 있어야 한다. 기존 유리 반사, 외부 주차장 불빛, 문틀의 가림과 유리를 통과한 약한 색 변화를 정확히 반영하라.

PEEK 상태에서는 눈을 거의 깜빡이지 않는 듯 똑바로 바라보고, 입은 닫혀 있지만 아주 약한 친절한 미소가 잘못 고정된 표정으로 보이게 한다. HOSTILE 상태에서는 같은 얼굴, 같은 위치, 같은 노출과 같은 가림을 한 픽셀도 움직이지 말고 유지한다. 오직 보이는 눈이 비정상적으로 더 크게 떠지고, 보이는 쪽 입꼬리가 해부학적으로 불편할 정도로 위로 당겨져 악독한 웃음으로 변하게 한다. 두 번째 상태에서도 얼굴이 가까워지거나 더 많이 드러나면 안 된다.

문, 벨, 모니터, 책상과 외부 배경은 바꾸지 않는다. 얼굴을 닦인 자국처럼 만들지 말고, 손이나 전신, 다른 얼굴, 발광하는 눈, 피와 상처를 추가하지 않는다. 공포는 동일한 얼굴이 벨 입력에 반응해 표정만 바꿨다는 사실에서 나와야 한다.
```

```text
안내판의 크기, 각도, 테두리와 주변 전화기·벨·책상을 그대로 유지한다. 다른 종이나 벽에 글씨를 복제하지 않는다. 피로 글자를 쓰는 손, 쓰이는 과정, 손자국, 룬과 영어 문자를 추가하지 않는다. 이미지 모델이 “죽어”를 정확히 만들지 못하면 빈 붉은 획 질감만 생성하고 글자는 별도 2D 합성으로 넣을 수 있도록 표면과 원근을 깨끗하게 보존하라.
```
