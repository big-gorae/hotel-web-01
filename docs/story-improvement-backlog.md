## 유지 원칙

- 모든 이상현상을 언니나 하나의 사건에서 태어난 존재로 설명하지 않는다.
- 언니가 된 엔티티는 외형만으로 언니라고 의심할 수 없어야 한다.
- 정체 공개 전 언니의 목소리, 얼굴, 경찰 배지 같은 직접 단서를 엔티티에 노출하지 않는다.
- 정체를 모른 채 주인공이 직접 죽인다는 결과는 유지한다.
- 관리자, 109호 안의 화자와 호텔 사장의 정체는 별도 결정 전까지 열어 둔다.
- 설명 팝업 없이 룰북 문장, 기록과 실제 행동으로 전달한다.
