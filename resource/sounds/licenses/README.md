# Sound License Records

Keep one license record per external sound source in this directory.

Recommended fields:

```text
Asset:
Type:
Author:
Submitted by:
Source:
Original source:
License:
License URL:
Downloaded on:
Commercial use:
Modification allowed:
Redistribution allowed:
Modifications:
```

Use `Modifications: None.` when the file is only renamed or copied without audio changes.

Do not add audio to the repository or release build when its source and usage rights cannot be verified.
