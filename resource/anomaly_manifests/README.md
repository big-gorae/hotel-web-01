# 이상현상 프레젠테이션 매니페스트

사용자가 MVP 적용을 승인한 게임 이미지만 이 디렉터리의 `<event_id>.json`으로 등록한다.

- 스키마: [schema.json](schema.json)
- 제작·인수인계 절차: [SceneLock 자산 인수인계 명세](../../docs/implementation/scenelock-handoff.md)
- 런타임 검증기: `res://scripts/horror/anomaly_presentation_manifest.gd`

예정 자산을 나타내는 빈 manifest나 가짜 SHA-256은 추가하지 않는다. 아직 제작되지 않은 상태는 콘텐츠 제작 계획 문서에서만 관리한다.

## 현재 연결된 MVP

`schema.json`을 제외한 이 디렉터리의 모든 JSON이 현재 연결된 MVP다.

- 생성 이미지: 빨간 객실등, 문 아래 피, 아기 얼굴 벽지, 인간 가죽 수건,
  지옥행 화살표, 끔찍한 액자, 샤워 커튼 안의 다리, 붉은 손자국 거울,
  끔찍한 화장실 거울, 109호 열린 문, 매달린 여자아이, 모니터 귀신,
  유리문 너머 얼굴
- 기존 생성 이미지: 붉은 세탁기, 가짜 어머니, 이불 속 아이, TV 귀신,
  내장 욕조, 빈 자살 로프, 열린 105호 옷장
- 직접 합성: `"죽어"` 안내판, 문틈의 돼지 가면 남자

`지옥의 거울` 아이콘은 장면 매니페스트가 아니라
`res://resource/images/items/hell_mirror.png`의 검은 임시 이미지다.

각 매니페스트는 원본 장면과 런타임 이미지의 SHA-256 및 캔버스 크기를 검증한다. 비주얼 업그레이드 시 정식 경로는 유지하고 이미지와 해당 해시만 교체한다.
